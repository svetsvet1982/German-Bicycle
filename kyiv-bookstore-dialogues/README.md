# «Тіні в книгарні» — 키예프 서점 연애 대화문 (우크라이나어 + 한국어)

4부 × 12화 × 100턴 = 총 48화 / 4,800턴

## 등장인물
- **Оксана Коваленко** (28) — 서점 «Старе Місто»(오래된 도시) 점원. 책 추천 달인, 언젠가 자기 출판사를 여는 게 꿈. 체르니히우 출신.
- **Андрій Мельник** (31) — 키예프 출신 건축 복원 전문가. 오랫동안 러시아어를 쓰다가 최근 우크라이나어로 바꾸고 문학을 읽기 시작함.
- **Степан Іванович** — 서점 주인, 70대, 엄격하지만 다정함.
- **Марічка** — 동료 점원, 옥사나의 절친.
- **Тарас** — 안드리의 친구, 장난꾸러기.
- **Кобзар** — 서점의 고양이.
- **пані Галина** — 옥사나의 어머니 / **баба Надія** — 할머니.

## 배경
키예프(Київ) 안드리이우스키 스푸스크(Андріївський узвіз) 근처 작은 서점 «Старе Місто». 흐레샤티크, 포딜, 키예보-페체르스카 라브라, 드니프로 강변 등.

## 난이도 설계 (초급 → 중고급)
| 부 | 수준 | 특징 |
|---|---|---|
| 1부 가을 | **초급 (A1~A2)** | 짧은 문장, 현재 시제 위주, 기초 어휘, 반복 패턴 (인사·가격·주문·취향) |
| 2부 겨울 | **초중급 (A2~B1)** | 과거·미래 시제, 접속사(тому що, але, коли), 명령형, 격변화 확대 |
| 3부 봄 | **중급 (B1~B2)** | 가정법(якби), 관계절, 감정·의견 표현, 긴 문장, 관용구 |
| 4부 여름 | **중고급 (B2~C1)** | 복문, 문어체·격식체, 속담·관용어, 뉘앙스, 추상적 주제 |

## 말투 규칙
- 1~2부 중반(19화 전까지): 서로 존칭 **Ви**
- 19화부터: 친근한 **ти** 로 전환
- 형식: `번호. **화자:** 우크라이나어` 다음 줄에 *한국어 번역*
