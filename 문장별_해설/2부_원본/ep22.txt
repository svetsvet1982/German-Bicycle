# 2부 22화: Rouladen und der erste Schnee / 롤라덴 그리고 첫눈
Jonas ¦ Sonntagnachmittag, Charlottenburg. Meine Mutter wohnt seit dreißig Jahren im selben Haus. ¦ 일요일 오후, 샤를로텐부르크. 어머니는 삼십 년째 같은 집에 살고 계신다. ¦ der Nachmittag, -e  —  오후 // wohnen  —  살다 // dasselbe  —  똑같은 ¦ Sonntagnachmittag, Charlottenburg는 시간과 장소를 나열한 생략문입니다. im selben Haus는 in + 3격입니다. ¦ seit dreißig Jahren은 seit + 3격으로 지속 기간을 나타냅니다. ¦ wohnt는 현재형입니다.
Jonas ¦ Ich stehe vor der Tür und halte einen Kuchen in beiden Händen. ¦ 나는 현관문 앞에 서서 두 손에 케이크를 들고 있다. ¦ der Kuchen, -  —  케이크 // die Tür, -en  —  문 // halten  —  들다 ¦ Ich stehe vor der Tür에서 vor + 3격은 위치를 나타냅니다. in beiden Händen은 in + 3격 복수입니다. ¦ halten은 손에 들고 있다는 뜻입니다. ¦ stehe, halte는 현재형입니다.
Mama ¦ Da bist du ja, mein Junge! Komm rein, du siehst durchgefroren aus. ¦ 왔구나, 우리 아들! 들어와, 꽁꽁 언 얼굴이네. ¦ durchgefroren  —  꽁꽁 언 // hereinkommen  —  들어오다 // der Junge, -n  —  아이, 소년 ¦ Komm rein은 du 명령형이고 du siehst ... aus는 분리동사 aussehen입니다. Da bist du ja는 반가움을 나타냅니다. ¦ mein Junge는 다정한 호칭입니다. ¦ bist, siehst ... aus는 현재형이고 Komm은 명령형입니다.
Mama ¦ Das Essen ist in zehn Minuten fertig. Die Rouladen schmoren schon seit zwei Stunden. ¦ 식사는 십 분 뒤면 돼. 롤라덴이 벌써 두 시간째 졸고 있어. ¦ die Roulade, -n  —  롤라덴(고기 말이) // schmoren  —  푹 졸이다 // fertig  —  준비된 ¦ in zehn Minuten은 in + 3격으로 몇 분 뒤를 나타냅니다. seit zwei Stunden은 seit + 3격으로 지속을 나타냅니다. ¦ Die Rouladen는 독일 가정식의 대표 요리입니다. ¦ ist, schmoren은 현재형입니다.
Jonas ¦ Hallo, Mama. Es riecht herrlich bis ins Treppenhaus. ¦ 안녕, 엄마. 계단까지 냄새가 정말 좋아요. ¦ herrlich  —  훌륭하게 // das Treppenhaus  —  계단실 // riechen  —  냄새가 나다 ¦ Es riecht herrlich에서 비인칭 es가 주어입니다. bis ins는 bis in das의 축약입니다. ¦ herrlich는 부사로 쓰여 매우 좋다는 뜻입니다. ¦ riecht는 현재형입니다.
Jonas ¦ Ich habe Felix' Lieblingskuchen mitgebracht, den mit den Walnüssen. ¦ 펠릭스가 제일 좋아하는 호두 케이크를 가져왔어요. ¦ der Lieblingskuchen  —  가장 좋아하는 케이크 // die Walnuss, -nüsse  —  호두 // mitbringen  —  가져오다 ¦ Felix' Lieblingskuchen에서 -s로 끝나는 이름의 소유격은 아포스트로피만 붙입니다. den mit den Walnüssen에서 den은 Kuchen을 가리키는 지시대명사입니다. ¦ mit den Walnüssen은 mit + 3격 복수입니다. ¦ habe ... mitgebracht는 현재완료입니다.
Mama ¦ Du vergisst nie etwas, das bei deinem Bruder Eindruck macht. ¦ 너는 동생에게 인상을 줄 만한 건 절대 잊지 않는구나. ¦ vergessen  —  잊다 // der Eindruck, -drücke  —  인상 // machen  —  만들다 ¦ etwas, das bei deinem Bruder Eindruck macht에서 das는 관계대명사이며 macht가 끝에 옵니다. nie etwas는 결코 아무것도 ~않는다는 뜻입니다. ¦ Eindruck machen은 인상을 준다는 표현입니다. ¦ vergisst, macht는 현재형입니다.
Mama ¦ Er ist schon da und deckt den Tisch. Setz dich schon mal, ich hole die Soße. ¦ 걔는 벌써 와서 식탁을 차리고 있어. 먼저 앉아 있어, 소스 가져올게. ¦ den Tisch decken  —  식탁을 차리다 // die Soße, -n  —  소스 // holen  —  가져오다 ¦ Setz dich는 sich setzen의 du 명령형입니다. Er ist schon da und deckt den Tisch에서 두 동사가 und로 연결됩니다. ¦ schon mal은 먼저라는 뜻의 구어 표현입니다. ¦ ist, deckt, hole은 현재형이고 Setz는 명령형입니다.
Felix ¦ Na, wenn das nicht der Aussteiger ist. Ich dachte schon, du hättest es dir anders überlegt. ¦ 이게 누구야, 탈출자님 아니신가. 마음이 바뀌어서 안 오는 줄 알았어. ¦ der Aussteiger, -  —  (직장·사회에서) 빠져나온 사람 // sich überlegen  —  마음먹다 // schon  —  벌써 ¦ Ich dachte schon, du hättest es dir anders überlegt는 접속법 II 과거로 추측을 나타냅니다. wenn das nicht ... ist는 놀람을 나타내는 구어 표현입니다. ¦ Aussteiger는 직장이나 길에서 벗어난 사람을 뜻합니다. ¦ dachte는 과거형이고 hättest ... überlegt는 접속법 II 과거입니다.
Jonas ¦ Der Aussteiger bringt Kuchen. Walnuss. Den hast du dir verdient. ¦ 탈출자가 케이크를 가져왔어. 호두. 넌 이걸 받을 자격이 있지. ¦ verdienen  —  받을 자격이 있다 // bringen  —  가져오다 // der Kuchen, -  —  케이크 ¦ Den hast du dir verdient에서 Den이 문두에 와 도치되었고 dir는 재귀 3격입니다. 동사 verdienen은 현재완료로 쓰였습니다. ¦ sich etwas verdienen은 ~를 누릴 자격이 있다는 표현입니다. ¦ bringt는 현재형이고 hast ... verdient는 현재완료입니다.
Felix ¦ Auch wenn ich dich auf Tante Ingrids Hochzeit als „den Lieferjungen der Familie" vorgestellt habe? ¦ 내가 잉그리드 이모 결혼식에서 너를 가족의 배달 소년이라고 소개했는데도? ¦ vorstellen  —  소개하다 // der Lieferjunge, -n  —  배달 소년 // die Hochzeit, -en  —  결혼식 ¦ Auch wenn ich ... vorgestellt habe에서 wenn절의 habe가 끝에 옵니다. als den Lieferjungen은 ~로서라는 als + 4격입니다. ¦ jemanden als etwas vorstellen은 누구를 ~로 소개한다는 표현입니다. ¦ vorgestellt habe는 현재완료입니다.
Jonas ¦ Das hast du gesagt, ja. Vor dem gesamten Verwandtenkreis. ¦ 그래, 네가 그렇게 말했지. 친척들 모두 앞에서. ¦ gesamt  —  전체의 // der Verwandtenkreis  —  친척 모임 // sagen  —  말하다 ¦ Das hast du gesagt에서 Das가 문두에 와 도치되었습니다. Vor dem gesamten Verwandtenkreis는 vor + 3격입니다. ¦ ja는 인정을 나타냅니다. ¦ hast ... gesagt는 현재완료입니다.
Felix ¦ Ich bin nicht stolz darauf. Ich war ein Idiot. ¦ 그게 자랑스럽진 않아. 내가 바보였지. ¦ stolz  —  자랑스러운 // der Idiot, -en  —  바보 // darauf  —  그것에 대해 ¦ stolz auf + 4격은 ~를 자랑스러워한다는 표현이며 여기서는 darauf로 대신합니다. Ich war ein Idiot에서 war는 과거형입니다. ¦ nicht stolz darauf는 부끄럽다는 뜻입니다. ¦ bin, war는 각각 현재형과 과거형입니다.
Felix ¦ Ich habe mich über dich lustig gemacht, weil ich Angst hatte, du hättest recht. ¦ 네 말이 맞을까 봐 두려워서 널 놀렸어. ¦ sich lustig machen über  —  놀리다 // recht haben  —  옳다 // die Angst, Ängste  —  두려움 ¦ weil ich Angst hatte, du hättest recht에서 hättest는 접속법 II로 가정을 나타냅니다. sich über + 4격 lustig machen이 쓰였습니다. ¦ Angst haben은 두려워한다는 표현입니다. ¦ habe ... gemacht는 현재완료이고 hatte는 과거형, hättest는 접속법 II입니다.
Jonas ¦ Recht womit, Felix? Dass man kündigen kann? Dass man nicht im Büro versauern muss? ¦ 무엇에 대해서 맞는다는 거야, 펠릭스? 사직할 수 있다는 거? 사무실에서 썩지 않아도 된다는 거? ¦ kündigen  —  그만두다 // versauern  —  시들다 // womit  —  무엇으로 ¦ Dass man kündigen kann?은 dass절을 독립적으로 쓴 의문문입니다. nicht ... muss는 필요하지 않다는 뜻입니다. ¦ Recht womit?는 생략된 의문문입니다. ¦ kann, muss는 현재형입니다.
Felix ¦ Dass es einen Ausweg gibt. Ich arbeite seit sieben Jahren in der Bank und träume seit fünf davon, auszusteigen. ¦ 출구가 있다는 거. 나는 칠 년째 은행에서 일하고 오 년째 그만두는 꿈을 꿔. ¦ der Ausweg, -e  —  출구 // träumen  —  꿈꾸다 // aussteigen  —  그만두다 ¦ Dass es einen Ausweg gibt에서 gibt이 끝에 옵니다. träume ... davon, auszusteigen은 davon과 zu 부정형이 결합한 구문입니다. ¦ seit sieben Jahren은 seit + 3격입니다. ¦ gibt, arbeite, träume는 현재형입니다.
Felix ¦ Aber ich habe Raten für die Wohnung und eine Familie, die auf mich zählt. ¦ 하지만 집 할부금이 있고 나를 믿고 의지하는 가족이 있어. ¦ die Rate, -n  —  할부금 // zählen auf  —  의지하다 // die Wohnung, -en  —  집 ¦ eine Familie, die auf mich zählt에서 die는 관계대명사이며 zählt가 끝에 옵니다. Raten für die Wohnung은 für + 4격입니다. ¦ auf jemanden zählen은 ~를 믿고 의지한다는 표현입니다. ¦ habe, zählt는 현재형입니다.
Jonas ¦ Ich habe auch Verantwortung. Nur eine andere. Und glaub mir, ich habe nachts Angst, dass ich mich verrechnet habe. ¦ 나도 책임이 있어. 다른 종류일 뿐이야. 그리고 믿어, 밤마다 내가 계산을 잘못한 건 아닌지 두려워. ¦ die Verantwortung, -en  —  책임 // sich verrechnen  —  계산을 잘못하다 // nachts  —  밤에 ¦ glaub mir는 glauben의 du 명령형이며 3격 mir를 취합니다. Angst, dass ich mich verrechnet habe에서 dass절의 habe가 끝에 옵니다. ¦ nachts는 밤마다라는 부사입니다. ¦ habe는 현재형이고 verrechnet habe는 현재완료입니다.
Felix ¦ Du? Du hast Angst? Du hast doch immer gewusst, wohin die Reise geht. ¦ 형이? 형이 두렵다고? 늘 여행이 어디로 가는지 알았잖아. ¦ die Reise, -n  —  여정 // wissen  —  알다 // immer  —  늘 ¦ Du hast doch immer gewusst, wohin die Reise geht에서 wohin절의 geht이 끝에 옵니다. doch는 상대가 알 법한 사실을 상기시킵니다. ¦ wohin die Reise geht는 어디로 가는지라는 간접 의문절입니다. ¦ hast ... gewusst는 현재완료이고 geht은 현재형입니다.
Jonas ¦ Ich wusste, wohin ich wollte. Nicht, ob ich dort glücklich werde. Das ist ein Unterschied. ¦ 어디로 가고 싶은지는 알았어. 거기서 행복해질지는 몰랐지. 그건 차이야. ¦ der Unterschied, -e  —  차이 // glücklich  —  행복한 // wollen  —  원하다 ¦ Ich wusste, wohin ich wollte에서 wollte 뒤 동사가 생략되었습니다. Nicht, ob ich dort glücklich werde는 ob절의 생략 구문입니다. ¦ Das ist ein Unterschied는 차이를 강조하는 문장입니다. ¦ wusste, wollte는 과거형이고 werde, ist는 현재형입니다.
Mama ¦ Essen ist fertig! Hände waschen, ihr beiden. ¦ 식사 준비됐어! 손 씻으렴, 너희 둘. ¦ waschen  —  씻다 // die Hand, Hände  —  손 // ihr beiden  —  너희 둘 ¦ Hände waschen은 부정형을 명령으로 쓴 표현입니다. ihr beiden은 둘을 함께 부르는 호칭입니다. ¦ Essen ist fertig는 식사 준비가 되었다는 정형 표현입니다. ¦ ist는 현재형입니다.
Mama ¦ Und Felix, stell die Gläser hin, nicht wieder diese Plastikbecher. ¦ 그리고 펠릭스, 유리잔을 놓아라, 또 그 플라스틱 컵은 안 돼. ¦ hinstellen  —  놓다 // das Glas, Gläser  —  유리잔 // der Plastikbecher, -  —  플라스틱 컵 ¦ stell ... hin은 분리동사 hinstellen의 du 명령형입니다. nicht wieder diese Plastikbecher는 동사가 생략된 문장입니다. ¦ nicht wieder는 또 ~는 안 된다는 뜻입니다. ¦ stell ... hin은 명령형입니다.
Felix ¦ Mama, ich bin zweiunddreißig. Ich darf doch wohl Plastikbecher benutzen. ¦ 엄마, 저 서른두 살이에요. 플라스틱 컵 정도는 써도 되잖아요. ¦ benutzen  —  사용하다 // wohl  —  아마도 // doch  —  ~잖아요 ¦ Ich darf doch wohl ... benutzen에서 darf는 허락을 나타냅니다. doch wohl은 당연히 되지 않느냐는 어조를 만듭니다. ¦ ich bin zweiunddreißig는 나이를 말하는 표현입니다. ¦ bin, darf는 현재형입니다.
Mama ¦ In meiner Küche bist du immer zwölf. Ab auf die Gläser. ¦ 내 부엌에서는 넌 언제나 열두 살이야. 어서 유리잔 놓아. ¦ die Küche, -n  —  부엌 // zwölf  —  열둘 // ab  —  어서 ¦ In meiner Küche bist du immer zwölf에서 in + 3격이 쓰였습니다. Ab auf die Gläser는 동사가 없는 구어 명령입니다. ¦ 어머니의 유머가 담긴 문장입니다. ¦ bist는 현재형입니다.
Jonas ¦ Beim Essen erzählt Mama von ihrer Nachbarin. Die will einen Bürgerantrag stellen, weil die Straßenlaterne vor ihrem Haus seit einem Jahr kaputt ist. ¦ 식사하면서 어머니는 이웃 이야기를 하신다. 그분은 집 앞 가로등이 일 년째 고장이라 주민 청원을 내려 한다. ¦ die Nachbarin, -nen  —  이웃 여성 // der Bürgerantrag, -träge  —  주민 청원 // die Straßenlaterne, -n  —  가로등 ¦ weil die Straßenlaterne ... kaputt ist에서 weil절의 ist가 끝에 옵니다. einen Antrag stellen은 신청서를 낸다는 표현입니다. ¦ seit einem Jahr는 seit + 3격입니다. ¦ erzählt, will, ist는 현재형입니다.
Jonas ¦ Ich merke, wie sehr ich dieses Gespräch über Alltägliches vermisst habe. Keine Fristen, keine Strategien, nur Rouladen und Rotkohl. ¦ 이런 일상적인 이야기를 얼마나 그리워했는지 깨닫는다. 기한도 전략도 없이 롤라덴과 적양배추뿐이다. ¦ der Rotkohl (단수)  —  적양배추 // vermissen  —  그리워하다 // alltäglich  —  일상적인 ¦ wie sehr ich ... vermisst habe는 간접 의문절이며 habe가 끝에 옵니다. Alltägliches는 형용사의 명사화입니다. ¦ Keine Fristen, keine Strategien은 동사가 없는 병렬 표현입니다. ¦ merke는 현재형이고 vermisst habe는 현재완료입니다.
Mama ¦ Jonas, du isst gar nichts. Schmeckt es dir nicht? ¦ 요나스, 아무것도 안 먹는구나. 맛이 없니? ¦ schmecken  —  맛이 나다 // gar nichts  —  전혀 아무것도 ~않다 // essen  —  먹다 ¦ Schmeckt es dir nicht?에서 schmecken은 3격 dir를 취합니다. du isst는 essen의 현재형으로 어간 모음이 바뀝니다. ¦ gar nichts는 전혀 아무것도라는 강조 표현입니다. ¦ isst, Schmeckt는 현재형입니다.
Jonas ¦ Es schmeckt fantastisch, Mama. Ich bin nur in Gedanken. ¦ 정말 맛있어요, 엄마. 그냥 생각에 잠겨 있었어요. ¦ fantastisch  —  환상적인 // der Gedanke, -n  —  생각 // nur  —  단지 ¦ in Gedanken sein은 생각에 잠겨 있다는 표현입니다. Es schmeckt fantastisch에서 es는 음식을 가리킵니다. ¦ Gedanke는 n-변화 명사입니다. ¦ schmeckt, bin은 현재형입니다.
Jonas ¦ Mama, ich muss dir etwas erzählen. Nicht alles, das darf ich nicht, aber das Wichtigste. ¦ 엄마, 말씀드릴 게 있어요. 전부는 아니에요, 그럴 수는 없으니까요. 하지만 가장 중요한 건요. ¦ erzählen  —  이야기하다 // das Wichtigste  —  가장 중요한 것 // dürfen  —  허락되다 ¦ Ich muss dir etwas erzählen에서 dir는 3격입니다. das Wichtigste는 최상급의 명사화입니다. ¦ Nicht alles, das darf ich nicht은 부정을 덧붙이는 구문입니다. ¦ muss, darf는 현재형입니다.
Jonas ¦ Ich helfe gerade ein paar Menschen, die schlecht behandelt wurden. Und ich glaube, es wird ein größeres Verfahren. ¦ 지금 부당한 대우를 받은 몇몇 사람들을 돕고 있어요. 그리고 더 큰 소송이 될 것 같아요. ¦ behandeln  —  대하다 // das Verfahren, -  —  소송 // ein paar  —  몇몇 ¦ Menschen, die schlecht behandelt wurden에서 die는 관계대명사이고 수동의 과거형이 끝에 옵니다. es wird ein größeres Verfahren은 werden + 명사 구문입니다. ¦ ein paar는 몇몇이라는 수량 표현입니다. ¦ helfe, glaube, wird는 현재형이고 wurden은 수동 과거형입니다.
Mama ¦ Das habe ich mir gedacht.
