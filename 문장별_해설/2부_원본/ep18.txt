# 2부 18화: Kaffee mit Herrn Brandt / 브란트 씨와의 커피
Jonas ¦ Mittwochmorgen, zehn vor neun. Das Café liegt in Mitte, zwischen einer Galerie und einem Anwaltsbüro, das ich gut kenne. Schmunzelnd stelle ich mein Rad ab. ¦ 수요일 아침 아홉 시 십 분 전. 카페는 미테 지구에 있고, 갤러리와 내가 잘 아는 법률사무소 사이에 끼어 있다. 나는 쓴웃음을 지으며 자전거를 세운다. ¦ schmunzeln  —  미소 짓다, 쓴웃음 짓다 // abstellen  —  세워 두다 // zwischen + 3격  —  ~ 사이에 ¦ Das Café liegt in Mitte, zwischen einer Galerie und einem Anwaltsbüro, das ich gut kenne에서 das는 중성 관계대명사로 Anwaltsbüro를 받고 kenne가 끝에 옵니다. Schmunzelnd는 현재분사가 부사처럼 쓰인 형태입니다. ¦ zwischen + 3격은 위치를 나타냅니다. 사직한 사무소와 같은 거리에 약속 장소가 있다는 점이 불편한 아이러니를 만듭니다. ¦ liegt, kenne, stelle ... ab는 현재형(Präsens)으로 서술 속 현재 장면을 묘사합니다.
Jonas ¦ Ich habe Hanna und Elif geschrieben, wo ich bin. Nicht aus Misstrauen, sondern aus Prinzip. Seit gestern Abend gilt bei mir die Regel: Niemand geht allein in ein Gespräch, von dem er nicht weiß, wohin es führt. ¦ 한나와 엘리프에게 내가 어디 있는지 메시지를 보냈다. 불신이 아니라 원칙에서다. 어제 저녁부터 내 규칙이 생겼다. 어디로 이어질지 모르는 대화에는 아무도 혼자 들어가지 않는다. ¦ das Misstrauen (단수)  —  불신 // das Prinzip, -ien  —  원칙 // führen  —  이끌다, 이어지다 ¦ Seit gestern Abend gilt bei mir die Regel에서 gelten은 규칙이 적용된다는 뜻이고 콜론 뒤에 규칙 내용이 이어집니다. ein Gespräch, von dem er nicht weiß, wohin es führt에서 von dem은 관계대명사 앞에 전치사가 놓인 형태이고 wohin절은 간접의문절로 führt가 끝에 옵니다. ¦ nicht aus Misstrauen, sondern aus Prinzip은 '불신이 아니라 원칙으로'라는 대조 구조입니다. 이전에 혼자 싸우던 요나스가 협력의 규칙을 세운 점이 눈에 띕니다. ¦ habe ... geschrieben은 현재완료(Perfekt)이고 gilt, weiß, führt는 현재형으로 일반적인 규칙을 말합니다.
Brandt ¦ Herr Keller! Pünktlich, wie ich es erwartet habe. Thomas Brandt. Nehmen Sie Platz, ich habe uns zwei Flat Whites bestellt. ¦ 켈러 씨! 예상대로 시간을 정확히 지키셨군요. 토마스 브란트입니다. 앉으세요, 플랫 화이트 두 잔 시켜 놨습니다. ¦ erwarten  —  기대하다, 예상하다 // Platz nehmen  —  앉다 // bestellen  —  주문하다 ¦ Pünktlich, wie ich es erwartet habe에서 wie절은 현재완료로 habe가 끝에 옵니다. Nehmen Sie Platz는 Sie 명령형이고 ich habe uns zwei Flat Whites bestellt에서 uns는 3격입니다. ¦ 상대의 취향을 묻지 않고 음료를 주문해 두는 행동은 주도권을 쥐려는 태도를 보여 줍니다. 친절한 말투와 통제하려는 태도가 함께 드러납니다. ¦ 명령형 Nehmen과 현재완료 habe ... erwartet, habe ... bestellt는 이미 이루어진 기대와 주문을 말합니다.
Jonas ¦ Guten Morgen, Herr Brandt. Danke, aber ich hätte lieber einen schwarzen Kaffee gehabt. ¦ 안녕하세요, 브란트 씨. 감사하지만 저는 블랙커피가 더 좋았을 텐데요. ¦ lieber  —  차라리 (gern의 비교급) // schwarz  —  검은 // hätte ... gehabt  —  가졌을 텐데 ¦ ich hätte lieber einen schwarzen Kaffee gehabt는 접속법 II 과거로 '그랬더라면 좋았을 텐데'라는 아쉬움을 정중하게 말합니다. einen schwarzen Kaffee에서 schwarzen은 남성 4격 부정관사 뒤의 형용사 어미입니다. ¦ lieber는 gern의 비교급으로 '더 선호하다'를 뜻합니다. 정중한 말투 속에서 상대의 일방적 주문에 조용히 거리를 두는 표현입니다. ¦ hätte ... gehabt는 접속법 II 과거(Konjunktiv II der Vergangenheit)로 이미 지나간 상황에 대한 정중한 아쉬움을 나타냅니다.
Brandt ¦ Dann bekommen Sie einen. Ich sehe schon, wir verstehen uns. Sie sind direkt, das mag ich. ¦ 그럼 블랙으로 드리죠. 이미 보니 우리는 말이 잘 통하겠군요. 직설적이시네요, 마음에 듭니다. ¦ sich verstehen  —  서로 이해하다 // direkt  —  직설적인 // mögen  —  좋아하다 ¦ Dann bekommen Sie einen에서 einen은 einen Kaffee를 생략한 남성 4격 대명사입니다. Ich sehe schon, wir verstehen uns에서 sehen 뒤에는 dass 없이 주절이 이어집니다. ¦ wir verstehen uns는 '서로 잘 통한다'는 뜻입니다. 상대를 추켜세우며 경계를 풀게 하려는 협상의 전형적인 도입입니다. ¦ bekommen, sehe, verstehen, sind, mag는 현재형(Präsens)으로 현재의 상황과 평가를 말합니다.
Jonas ¦ Ich bin neugierig, was Sie von mir wollen. Eine Einladung zum Kaffee kommt bei Ihrer Firma nicht oft vor. ¦ 제게 무엇을 원하시는지 궁금합니다. 귀사에서 커피 초대가 흔한 일은 아닐 텐데요. ¦ neugierig  —  궁금한 // vorkommen  —  일어나다, 있다 // die Einladung, -en  —  초대 ¦ Ich bin neugierig, was Sie von mir wollen에서 was절은 간접의문절로 wollen이 끝에 옵니다. Eine Einladung zum Kaffee kommt ... nicht oft vor에서 분리동사 vorkommen의 vor가 문장 끝에 옵니다. ¦ nicht oft vorkommen은 '자주 있지 않다'를 완곡하게 말하는 표현입니다. 정중한 비꼼으로 상대의 의도를 직접 묻는 화법입니다. ¦ bin, wollen, kommt ... vor는 현재형(Präsens)으로 현재의 호기심과 일반적 사실을 말합니다.
Brandt ¦ Nun, ich hatte gehofft, wir können das Missverständnis ausräumen. Sie haben unserem Disponenten Ärger gemacht, und mein Team ist ... nervös. ¦ 글쎄요, 오해를 풀 수 있기를 바랐습니다. 켈러 씨가 우리 배차 담당자에게 문제를 일으켰고 제 팀이 불안해하고 있어서요. ¦ das Missverständnis, -se  —  오해 // ausräumen  —  제거하다, 해소하다 // nervös  —  불안해하는 ¦ ich hatte gehofft, wir können das Missverständnis ausräumen에서 hatte gehofft는 과거완료이고 뒤의 내용은 dass 없이 주절 어순입니다. ausräumen은 분리동사지만 조동사와 함께 원형으로 문장 끝에 옵니다. ¦ Ärger machen은 '문제를 일으키다'입니다. Missverständnis라는 단어는 문제의 책임을 상대에게 돌리지 않고 가볍게 포장하는 완곡어법입니다. ¦ hatte gehofft는 과거완료(Plusquamperfekt)로 과거 이전의 기대를 말하고 können은 현재형, haben ... gemacht는 현재완료입니다.
Jonas ¦ Ein Missverständnis. Interessant. Ich habe nur eine einfache Frage gestellt: Wer hat entschieden, einen Fahrer ohne Begründung zu sperren? ¦ 오해라니 흥미롭군요. 저는 단순한 질문 하나만 했습니다. 이유도 없이 배달원을 정지시키기로 누가 결정했나요? ¦ eine Frage stellen  —  질문하다 // sperren  —  정지시키다 // ohne Begründung  —  이유 없이 ¦ Ich habe nur eine einfache Frage gestellt는 현재완료이고 stellen은 Frage와 함께 쓰는 연어입니다. Wer hat entschieden, ... zu sperren?에서 zu부정사구가 이어집니다. ¦ Interessant는 감정 없이 상황을 평가할 때 쓰는 법률가다운 말투입니다. 상대가 쓴 '오해'라는 단어를 되받아 쟁점을 다시 분명히 합니다. ¦ habe ... gestellt, hat entschieden은 현재완료(Perfekt)로 이미 한 질문과 이미 내려진 결정을 말합니다.
Brandt ¦ Das war eine automatische Entscheidung, bei der leider ein Fehler passiert ist. Wir haben Dennis Wagner bereits wieder freigeschaltet. Mit einer Entschuldigung. ¦ 그건 자동으로 이루어진 결정이었고 유감스럽게도 오류가 발생했습니다. 데니스 바그너 씨 계정은 이미 다시 활성화했습니다. 사과도 함께요. ¦ freischalten  —  (계정을) 활성화하다 // der Fehler, -  —  오류 // die Entschuldigung, -en  —  사과 ¦ bei der leider ein Fehler passiert ist에서 bei der는 여성 3격 관계대명사 앞의 전치사이고 passiert ist의 ist가 끝에 옵니다. Wir haben ... bereits wieder freigeschaltet는 분리동사 freischalten의 현재완료입니다. ¦ 앞서 린트너가 말한 '자동 시스템'이라는 설명과 일관되게 책임을 기계에 돌립니다. 이미 대응했다고 강조해 법적 분쟁의 필요성을 약화시키려는 수법입니다. ¦ war는 과거형이고 passiert ist, haben ... freigeschaltet는 현재완료(Perfekt)로 이미 있었던 오류와 조치를 말합니다.
Jonas ¦ Dann ist ja alles gut. Warum sitzen wir dann hier? ¦ 그럼 다 해결된 거네요. 그런데 왜 여기 앉아 있는 거죠? ¦ warum  —  왜 // dann  —  그렇다면 // ja  —  (불변화사) 그렇군요 ¦ Dann ist ja alles gut에서 ja는 반어적인 어감을 주는 불변화사입니다. Warum sitzen wir dann hier?는 W-의문문으로 정동사 sitzen이 2번째입니다. ¦ Dann ist ja alles gut은 말 그대로 받아들이면 안 되는 반어적 표현입니다. 형식적인 해결과 실질적 의도를 꿰뚫는 정확한 반문입니다. ¦ ist와 sitzen은 현재형(Präsens)으로 현재 상황에 대한 평가와 질문을 말합니다.
Brandt ¦ Weil ich glaube, dass hinter den Kulissen mehr passiert, als uns lieb ist. Es gibt Gerüchte über eine Fahrerinitiative. „Rad und Recht", nicht wahr? ¦ 막후에서 우리가 바라는 것보다 더 많은 일이 벌어지고 있다고 생각해서요. 배달원 모임에 대한 소문이 있더군요. "라트 운트 레히트", 맞죠? ¦ hinter den Kulissen  —  막후에서 // das Gerücht, -e  —  소문 // nicht wahr?  —  그렇지 않나요? ¦ Weil ich glaube, dass hinter den Kulissen mehr passiert, als uns lieb ist에서 weil절 안에 dass절이 중첩되고 als 비교절의 정동사 ist가 끝에 옵니다. Es gibt Gerüchte는 존재를 말하는 es gibt 구문입니다. ¦ als uns lieb ist는 '우리가 바라는 것보다'라는 관용 비교입니다. 어젯밤 설립된 모임의 이름을 정확히 아는 것은 정보가 새어 나갔다는 증거입니다. ¦ glaube, passiert, ist, gibt은 현재형(Präsens)으로 현재의 판단과 소문의 존재를 말합니다.
Jonas ¦ Interessant, wie schnell Gerüchte sich verbreiten. Gestern Abend war der Name noch nicht einmal auf Papier. ¦ 소문이 얼마나 빨리 퍼지는지 흥미롭네요. 어제 저녁에는 그 이름이 종이에 적히지도 않았는데요. ¦ sich verbreiten  —  퍼지다 // nicht einmal  —  ~조차 ~않다 // der Name, -n  —  이름 ¦ Interessant, wie schnell Gerüchte sich verbreiten에서 wie절은 간접의문절이며 재귀동사 verbreiten이 끝에 옵니다. Gestern Abend war der Name noch nicht einmal auf Papier에서 noch nicht einmal은 '아직 ~조차 아닌'입니다. ¦ 이름이 종이에도 적히지 않았다는 말로 정보 유출의 경로를 암시적으로 추궁합니다. 직설적 비난 대신 사실을 던져 상대의 반응을 보는 방식입니다. ¦ verbreiten은 현재형(Präsens)이고 war는 과거형(Präteritum)으로 어제 저녁의 상태를 말합니다.
Brandt ¦ Wir leben in einer vernetzten Welt, Herr Keller. Aber lassen Sie uns nicht über Quellen sprechen. Lassen Sie uns über Lösungen sprechen. ¦ 우리는 연결된 세상에 살고 있잖습니까, 켈러 씨. 하지만 출처 이야기는 하지 맙시다. 해결책을 이야기합시다. ¦ vernetzt  —  연결된 // die Quelle, -n  —  출처 // die Lösung, -en  —  해결책 ¦ Lassen Sie uns ... sprechen은 '~합시다'라는 권유의 Sie 명령형이고 nicht über Quellen sprechen과 über Lösungen sprechen이 대조됩니다. ¦ Lassen Sie uns ...는 격식 있는 공동 제안 표현입니다. 불편한 질문을 피하고 대화를 해결책으로 돌리는 화법입니다. ¦ leben은 현재형이고 Lassen Sie ... sprechen은 명령형으로 지금의 제안을 나타냅니다.
Jonas ¦ Gern. Dann nennen Sie mir bitte Ihre Lösung. Ich bin gespannt. ¦ 좋습니다. 그럼 귀하의 해결책을 말씀해 주세요. 기대됩니다. ¦ gespannt sein  —  기대하다 // nennen (nannte – genannt)  —  말하다, 언급하다 // gern  —  기꺼이 ¦ Dann nennen Sie mir bitte Ihre Lösung에서 nennen은 3격(mir)과 4격(Ihre Lösung)을 취합니다. Ich bin gespannt는 sein + gespannt 구문입니다. ¦ Ich bin gespannt는 정중하게 상대의 제안을 요구하는 표현입니다. 침착함을 유지하며 상대에게 먼저 패를 보이게 만듭니다. ¦ nennen은 명령형이고 bin은 현재형(Präsens)으로 지금의 기대를 말합니다.
Brandt ¦ Drei Punkte. Erstens: Herr Wagner erhält eine Entschädigung, fünftausend Euro, für die entstandenen Unannehmlichkeiten. Zweitens: Wir schaffen künftig eine transparente Beschwerdestelle. ¦ 세 가지입니다. 첫째, 바그너 씨에게 불편을 끼친 데 대한 보상으로 오천 유로를 지급합니다. 둘째, 앞으로 투명한 불만 접수 창구를 만들겠습니다. ¦ die Entschädigung, -en  —  보상 // entstanden  —  발생한 // künftig  —  앞으로 ¦ Herr Wagner erhält eine Entschädigung에서 erhalten은 받는다는 뜻으로 격식체입니다. für die entstandenen Unannehmlichkeiten에서 entstanden은 과거분사가 형용사로 쓰였고 복수 4격 어미 -en이 붙었습니다. ¦ Unannehmlichkeiten는 '불편, 폐'라는 뜻의 완곡어로 해고를 사소한 문제로 축소하는 표현입니다. 금전 보상과 개선 약속으로 갈등을 조기 종결하려는 시도입니다. ¦ erhält, schaffen은 현재형(Präsens)으로 현재 제안하는 조치를 말합니다.
Jonas ¦ Das klingt großzügig. Und der dritte Punkt? Bei großzügigen Angeboten gibt es meist einen Haken. ¦ 관대하게 들리는군요. 세 번째는요? 관대한 제안에는 대개 함정이 있기 마련이죠. ¦ großzügig  —  관대한 // der Haken, -  —  함정, 걸림돌 // meist  —  대개 ¦ Das klingt großzügig는 klingen + 형용사입니다. Bei großzügigen Angeboten gibt es meist einen Haken에서 großzügigen은 복수 3격 어미 -en입니다. ¦ einen Haken haben는 '함정이 있다'는 관용 표현입니다. 침착한 말투로 상대 제안의 허점을 미리 짚어 내는 베테랑 법률가의 태도입니다. ¦ klingt와 gibt은 현재형(Präsens)으로 현재의 인상과 일반적 경험칙을 말합니다.
Brandt ¦ Drittens: Wir würden uns freuen, wenn Sie als juristischer Berater für SchnellRad arbeiten. Sehr gut bezahlt, flexible Zeiten. Sie kennen die Branche, Sie sind ein Mann der Praxis. ¦ 셋째, 켈러 씨가 슈넬라트의 법률 자문으로 일해 주시면 기쁘겠습니다. 보수가 아주 좋고 근무 시간도 유연합니다. 이 업계를 아시고 실무형이시니까요. ¦ der Berater, -  —  자문 // die Branche, -n  —  업계 // flexibel  —  유연한 ¦ Wir würden uns freuen, wenn Sie ... arbeiten에서 würden uns freuen은 접속법 II로 정중한 소망을 표현하고 wenn절의 정동사 arbeiten이 끝에 옵니다.
