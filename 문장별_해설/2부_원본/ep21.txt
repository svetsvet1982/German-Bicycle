# 2부 21화: Eine Lieferung nach Marzahn / 마르찬으로 가는 배달
Jonas ¦ Freitagabend, kurz nach sieben. Mein Handy piept. ¦ 금요일 저녁 일곱 시 조금 넘어서. 휴대폰이 울린다. ¦ piepen  —  삑삑 울리다 // kurz nach  —  ~조금 지나서 // der Abend, -e  —  저녁 ¦ Freitagabend, kurz nach sieben은 동사 없는 시간 설정 문장입니다. Mein Handy piept는 주어와 동사로 이루어진 간단한 문장입니다. ¦ kurz nach + 시각은 조금 지났다는 표현입니다. ¦ piept는 현재형으로 장면을 생생하게 보여 줍니다.
Jonas ¦ Eine neue Tour: zweimal Pizza, ein Salat, Lieferadresse Marzahn. ¦ 새 배달이다. 피자 두 판, 샐러드 하나, 배달지는 마르찬. ¦ die Tour, -en  —  배달 // die Lieferadresse, -n  —  배달 주소 // der Salat, -e  —  샐러드 ¦ 콜론 뒤에 명사만 나열한 생략문입니다. zweimal Pizza에서 zweimal은 두 번이라는 부사입니다. ¦ Lieferadresse는 Lieferung과 Adresse의 합성어입니다. ¦ 동사가 없는 문장이라 상황 설명의 느낌을 줍니다.
Jonas ¦ Der Name des Kunden: Kowalski. ¦ 고객 이름은 코발스키. ¦ der Kunde, -n  —  고객 // der Name, -n  —  이름 // des Kunden  —  고객의 ¦ des Kunden은 남성 약변화 명사의 2격입니다. 콜론 뒤에 고유명사 하나만 놓아 긴장감을 줍니다. ¦ Kunde는 n-변화 명사입니다. ¦ 동사가 없는 문장입니다.
Jonas ¦ Kowalski. Es gibt Tausende davon in Berlin. ¦ 코발스키. 베를린에는 수천 명이 있는 이름이다. ¦ Tausende  —  수천 // davon  —  그중에 // es gibt  —  ~이 있다 ¦ es gibt + 4격은 존재를 나타내는 구문입니다. Tausende는 수사의 명사화로 대문자로 씁니다. ¦ davon은 da + von의 대명사 부사입니다. ¦ gibt은 현재형입니다.
Jonas ¦ Trotzdem schlägt mein Herz auf einmal schneller. ¦ 그런데도 심장이 갑자기 더 빨리 뛴다. ¦ trotzdem  —  그럼에도 // auf einmal  —  갑자기 // schneller  —  더 빨리 ¦ Trotzdem이 문두에 와서 동사 schlägt가 두 번째 자리에 옵니다. schneller는 schnell의 비교급입니다. ¦ das Herz schlägt는 심장이 뛴다는 표현입니다. ¦ schlägt는 현재형입니다.
Jonas ¦ Ich sage mir, dass das Unsinn ist, und fahre los. ¦ 말도 안 되는 생각이라고 스스로에게 말하고 출발한다. ¦ der Unsinn (단수)  —  말도 안 되는 일 // losfahren  —  출발하다 // sich sagen  —  스스로에게 말하다 ¦ dass das Unsinn ist에서 dass절의 동사 ist가 끝에 옵니다. fahre ... los는 분리동사 losfahren입니다. ¦ sich etwas sagen은 속으로 생각한다는 뜻입니다. ¦ sage, ist, fahre는 현재형입니다.
Jonas ¦ Der Weg nach Marzahn dauert fast vierzig Minuten. ¦ 마르찬까지 가는 데 거의 사십 분이 걸린다. ¦ dauern  —  걸리다 // fast  —  거의 // der Weg, -e  —  길 ¦ Der Weg ... dauert fast vierzig Minuten에서 시간 4격이 목적어처럼 쓰입니다. nach Marzahn은 도시나 지역명 앞의 nach입니다. ¦ dauern은 시간이 걸린다는 뜻입니다. ¦ dauert는 현재형입니다.
Jonas ¦ Ich fahre entlang der Landsberger Allee, vorbei an Tankstellen und Supermärkten, und je weiter ich komme, desto größer werden die Häuser. ¦ 란츠베르거 알레를 따라 주유소와 슈퍼마켓을 지나 달리는데, 갈수록 건물이 점점 커진다. ¦ vorbei an  —  ~을 지나서 // je ... desto  —  ~할수록 더 ~하다 // die Tankstelle, -n  —  주유소 ¦ je weiter ich komme, desto größer werden die Häuser는 je + 비교급, desto + 비교급 구문입니다. je절은 동사가 끝에 옵니다. ¦ entlang der Landsberger Allee는 entlang가 2격 뒤에 올 수 있는 표현입니다. ¦ fahre, komme, werden은 현재형입니다.
Jonas ¦ Dann stehen sie vor mir, die Plattenbauten, grau und lang wie Güterzüge, mit Balkonen voller Satellitenschüsseln. ¦ 그러고는 눈앞에 프리패브 건물이 나타난다. 화물 열차처럼 길고 회색이며, 위성 안테나가 가득한 발코니가 달려 있다. ¦ der Plattenbau, -ten  —  프리패브 건물 // der Güterzug, -züge  —  화물 열차 // die Satellitenschüssel, -n  —  위성 안테나 ¦ Dann stehen sie vor mir에서 Dann이 문두에 와 도치되었습니다. voller + 2격(복수)은 ~로 가득한이라는 뜻입니다. ¦ wie Güterzüge는 비교를 나타내는 wie입니다. ¦ stehen은 현재형입니다.
Jonas ¦ Die Hausnummer 14 liegt in einem Block mit achtzehn Stockwerken. ¦ 14번지는 십팔 층짜리 건물에 있다. ¦ die Hausnummer, -n  —  번지 // das Stockwerk, -e  —  층 // der Block, Blöcke  —  건물 단지 ¦ in einem Block mit achtzehn Stockwerken에서 in + 3격은 위치를, mit + 3격은 특징을 나타냅니다. ¦ achtzehn Stockwerke는 층수를 나타내는 표현입니다. ¦ liegt는 현재형입니다.
Jonas ¦ Ich schließe das Rad an einen Laternenpfahl an und nehme die Tasche. ¦ 자전거를 가로등 기둥에 묶고 가방을 든다. ¦ anschließen  —  묶다 // der Laternenpfahl, -pfähle  —  가로등 기둥 // die Tasche, -n  —  가방 ¦ schließe ... an은 분리동사 anschließen입니다. an einen Laternenpfahl은 an + 4격(방향)입니다. ¦ Tasche는 배달용 가방을 뜻합니다. ¦ schließe ... an, nehme는 현재형입니다.
Jonas ¦ Im Treppenhaus riecht es nach Reinigungsmittel und nach Essen aus vierzig Küchen. ¦ 계단실에서는 세제 냄새와 마흔 가구 부엌의 음식 냄새가 난다. ¦ das Treppenhaus, -häuser  —  계단실 // das Reinigungsmittel, -  —  세제 // die Küche, -n  —  부엌 ¦ es riecht nach + 3격은 ~냄새가 난다는 구문입니다. aus vierzig Küchen은 aus + 3격 복수입니다. ¦ 냄새로 장면을 묘사하는 감각적 표현입니다. ¦ riecht는 현재형입니다.
Jonas ¦ Der Aufzug ist kaputt. Auf einem Zettel steht: „Außer Betrieb. Wir bitten um Verständnis." ¦ 엘리베이터는 고장이다. 쪽지에 이렇게 적혀 있다. '운행 중단. 양해 부탁드립니다.' ¦ der Aufzug, -züge  —  엘리베이터 // außer Betrieb  —  운행 중단 // das Verständnis (단수)  —  이해 ¦ Der Aufzug ist kaputt는 상태를 나타내는 술어 형용사 문장입니다. Wir bitten um Verständnis에서 bitten um + 4격이 쓰입니다. ¦ außer Betrieb는 안내문의 정형 표현입니다. ¦ ist, steht, bitten은 현재형입니다.
Jonas ¦ Achtzehn Stockwerke zu Fuß, mit zwei Pizzen und einem Salat. Das ist der Preis für Kowalski. ¦ 피자 두 판과 샐러드를 들고 걸어서 십팔 층. 그게 코발스키의 대가다. ¦ zu Fuß  —  걸어서 // der Preis, -e  —  값 // die Pizza, Pizzen  —  피자 ¦ Achtzehn Stockwerke zu Fuß는 동사가 없는 생략문입니다. Das ist der Preis für Kowalski에서 für + 4격이 쓰입니다. ¦ zu Fuß는 걸어서라는 관용 표현입니다. ¦ ist는 현재형입니다.
Jonas ¦ Beim zehnten Stock bleibe ich keuchend stehen. Meine Beine zittern, und ich lache über mich selbst. ¦ 십 층에서 헐떡이며 멈춰 선다. 다리가 떨리고 나는 자신을 보며 웃는다. ¦ keuchend  —  헐떡이며 // zittern  —  떨다 // lachen über  —  ~를 보고 웃다 ¦ bleibe ... stehen은 stehen bleiben의 분리 형태입니다. lache über mich selbst에서 über + 4격이 쓰이며 selbst는 강조입니다. ¦ keuchend은 현재분사로 동시 상황을 나타냅니다. ¦ bleibe, zittern, lache는 현재형입니다.
Jonas ¦ Früher bin ich dreimal in der Woche gelaufen. Heute trage ich eine Tasche Pizza durch ein Treppenhaus und fühle mich wie ein Marathonläufer. ¦ 예전에는 일주일에 세 번 달렸다. 지금은 피자 가방을 들고 계단을 오르며 마라톤 선수가 된 기분이다. ¦ der Marathonläufer, -  —  마라톤 선수 // dreimal in der Woche  —  일주일에 세 번 // laufen  —  달리다 ¦ bin ... gelaufen은 laufen의 현재완료로 sein을 씁니다. dreimal in der Woche는 빈도 표현입니다. ¦ fühle mich wie ...는 ~처럼 느낀다는 표현입니다. ¦ bin ... gelaufen은 현재완료이고 trage, fühle는 현재형입니다.
Jonas ¦ Im achtzehnten Stock empfängt mich ein Flur mit Linoleum und einer einzigen Glühbirne, die flackert. ¦ 십팔 층에서는 리놀륨 바닥과 깜박이는 전구 하나가 있는 복도가 나를 맞는다. ¦ der Flur, -e  —  복도 // die Glühbirne, -n  —  전구 // flackern  —  깜박이다 ¦ ein Flur mit Linoleum und einer einzigen Glühbirne, die flackert에서 die는 관계대명사이고 flackert가 끝에 옵니다. im achtzehnten Stock은 서수 + Stock입니다. ¦ einzig은 하나뿐인이라는 형용사입니다. ¦ empfängt, flackert는 현재형입니다.
Jonas ¦ Tür 175. Ein Fußabtreter mit der Aufschrift „Willkommen", darunter ein Paar sorgfältig geputzter Schuhe. ¦ 175호. '환영합니다'라고 쓰인 발 매트, 그 아래 정성껏 닦은 신발 한 켤레. ¦ der Fußabtreter, -  —  발 매트 // die Aufschrift, -en  —  글귀 // sorgfältig  —  정성껏 ¦ Tür 175는 생략문입니다. ein Paar sorgfältig geputzter Schuhe에서 geputzter는 2격 복수 형용사 어미입니다. ¦ ein Paar는 한 켤레라는 수량 표현입니다. ¦ 동사가 없는 묘사 문장입니다.
Jonas ¦ Ich klingle. Drinnen höre ich Schritte, langsam, gleichmäßig, begleitet von einem metallischen Klacken. ¦ 초인종을 누른다. 안에서 발소리가 들린다. 느리고 일정하며 금속이 부딪히는 소리가 함께 난다. ¦ klingeln  —  초인종을 누르다 // gleichmäßig  —  일정한 // das Klacken (단수)  —  딱딱 소리 ¦ begleitet von einem metallischen Klacken은 과거분사 구문으로 동반 소리를 나타냅니다. Drinnen höre ich Schritte에서 Drinnen이 문두에 와 도치되었습니다. ¦ 금속성 소리는 목발을 암시합니다. ¦ klingle, höre는 현재형입니다.
Nina ¦ Moment! Ich komme! Papa, bleib sitzen, ich mache das! ¦ 잠깐만요! 가요! 아빠, 앉아 계세요, 제가 열게요! ¦ bleib sitzen  —  앉아 있어요 // der Moment, -e  —  잠깐 // machen  —  하다 ¦ bleib sitzen은 du 명령형입니다. ich mache das는 내가 할게라는 구어체입니다. ¦ Moment!는 잠시만이라는 외침입니다. ¦ komme, mache는 현재형이고 bleib는 명령형입니다.
Jonas ¦ Die Tür geht auf. Eine junge Frau, vielleicht Anfang zwanzig, mit müden Augen und einem freundlichen Lächeln. ¦ 문이 열린다. 스물 갓 넘은 듯한 젊은 여성이 지친 눈과 다정한 미소를 띠고 서 있다. ¦ aufgehen  —  열리다 // das Lächeln (단수)  —  미소 // müde  —  피곤한 ¦ Die Tür geht auf에서 aufgehen은 분리동사입니다. Anfang zwanzig는 이십 대 초반이라는 표현입니다. ¦ vielleicht는 추측의 부사입니다. ¦ geht ... auf는 현재형입니다.
Nina ¦ Entschuldigung, die Klingel ist so laut. Mein Vater erschrickt immer. ¦ 죄송해요, 초인종이 너무 시끄러워요. 아빠가 늘 놀라세요. ¦ erschrecken  —  놀라다 // laut  —  시끄러운 // die Klingel, -n  —  초인종 ¦ die Klingel ist so laut에서 so는 정도를 강조합니다. erschrickt는 erschrecken의 현재형(불규칙)입니다. ¦ Entschuldigung은 사과 인사입니다. ¦ ist, erschrickt는 현재형입니다.
Jonas ¦ Guten Abend. Ihre Bestellung von der Pizzeria Napoli. ¦ 안녕하세요. 피자 나폴리에서 주문하신 음식입니다. ¦ die Bestellung, -en  —  주문 // die Pizzeria, -s  —  피자 가게 // der Abend, -e  —  저녁 ¦ Ihre Bestellung von der Pizzeria Napoli는 동사 없는 인사말입니다. von der Pizzeria는 von + 3격입니다. ¦ Guten Abend은 저녁 인사입니다. ¦ 동사가 없는 문장입니다.
Jonas ¦ Zweimal Margherita und einmal Salat. Das macht neunzehn Euro fünfzig. ¦ 마르게리타 두 판과 샐러드 하나입니다. 십구 유로 오십 센트입니다. ¦ das macht  —  합계는 ~입니다 // zweimal  —  두 번, 두 개 // der Euro, -  —  유로 ¦ Das macht neunzehn Euro fünfzig에서 macht는 합계를 말하는 정형 표현입니다. ¦ Euro 뒤 숫자는 센트를 나타냅니다. ¦ macht는 현재형입니다.
Nina ¦ Danke. Papa, hast du das Geld? Ach nein, ich habe es. Hier, behalten Sie den Rest. ¦ 고맙습니다. 아빠, 돈 있어요? 아, 아니에요, 제가 가지고 있어요. 여기 거스름돈은 가지세요. ¦ behalten  —  가지다 // der Rest, -e  —  나머지 // das Geld (단수)  —  돈 ¦ hast du das Geld?는 동사가 앞에 오는 의문문입니다. Behalten Sie는 존칭 명령형입니다. ¦ den Rest behalten은 거스름돈을 가진다는 표현입니다. ¦ hast, habe는 현재형이고 Behalten은 명령형입니다.
Jonas ¦ Das ist zu viel. Sie haben mir fünf Euro Trinkgeld gegeben. ¦ 너무 많아요. 팁으로 오 유로를 주셨네요. ¦ das Trinkgeld, -er  —  팁 // zu viel  —  너무 많은 // geben  —  주다 ¦ Sie haben mir fünf Euro Trinkgeld gegeben에서 mir는 3격입니다. 현재완료로 이미 준 상황을 말합니다. ¦ zu viel은 지나치게 많다는 표현입니다. ¦ ist는 현재형이고 haben ... gegeben은 현재완료입니다.
Nina ¦ Sie haben achtzehn Stockwerke zu Fuß gemacht. Der Aufzug ist seit drei Wochen kaputt. Das ist das Mindeste. ¦ 십팔 층을 걸어 올라오셨잖아요. 엘리베이터는 삼 주째 고장이에요. 이건 최소한의 성의예요. ¦ das Mindeste  —  최소한 // kaputt  —  고장 난 // seit drei Wochen  —  삼 주 전부터 ¦ Sie haben ... zu Fuß gemacht는 현재완료입니다. seit drei Wochen은 seit + 3격 복수로 지속 기간을 나타냅니다. ¦ das Mindeste는 최상급의 명사화입니다. ¦ haben ... gemacht는 현재완료이고 ist, ist는 현재형입니다.
Piotr ¦ Nina, wer ist da? Lass den jungen Mann herein, es zieht. ¦ 니나, 누구니? 젊은이를 들어오게 해라, 외풍이 든다. ¦ hereinlassen  —  들어오게 하다 // es zieht  —  외풍이 든다 // wer  —  누구 ¦ Lass den jungen Mann herein은 du 명령형이고 lassen + 4격 + herein 구문입니다. es zieht는 비인칭 주어로 외풍을 말합니다. ¦ den jungen Mann은 약변화 형용사 4격입니다. ¦ ist, zieht는 현재형이고 Lass는 명령형입니다.
Nina ¦ Der Lieferant, Papa. Aber er sieht müde aus. Möchten Sie einen Tee? ¦ 배달원이에요, 아빠. 그런데 피곤해 보이세요. 차 한 잔 하실래요? ¦ der Lieferant, -en  —  배달원 // aussehen  —  ~처럼 보이다 // der Tee, -s  —  차 ¦ er sieht müde aus는 분리동사 aussehen의 현재형입니다. Möchten Sie einen Tee?는 공손한 권유입니다. ¦ Der Lieferant는 약변화 명사입니다. ¦ sieht ... aus, Möchten은 현재형입니다.
Jonas ¦ Ich müsste eigentlich gleich weiter. Die nächste Tour wartet. ¦ 사실 곧 가 봐야 해요. 다음 배달이 기다려요. ¦ eigentlich  —  사실은 // gleich  —  곧 // warten  —  기다리다 ¦ Ich müsste ... weiter에서 müsste는 접속법 II로 완곡한 표현입니다. 동사 gehen이 생략된 구어 구문입니다. ¦ gleich weiter는 곧 이동한다는 뜻의 생략 표현입니다. ¦ müsste는 접속법 II이고 wartet는 현재형입니다.
Piotr ¦ Eine Tasse Tee hat noch niemanden aufgehalten. Setzen Sie sich, junger Mann. Nina, bring die Tassen. ¦ 차 한 잔이 누구를 붙잡은 적은 없어요. 앉으세요, 젊은이. 니나, 찻잔 가져와라. ¦ aufhalten  —  붙잡아 두다 // die Tasse, -n  —  찻잔 // bringen  —  가져오다 ¦ hat noch niemanden aufgehalten에서 noch niemanden은 지금까지 아무도 ~않았다는 뜻입니다.
