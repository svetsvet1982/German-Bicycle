# 2부 21화: Eine Lieferung nach Marzahn / 마르찬으로 가는 배달
Jonas ¦ Freitagabend, kurz nach sieben. Mein Handy piept: eine neue Tour, Pizza und Salat, Lieferadresse Marzahn, achtzehnter Stock. Name des Kunden: Kowalski. ¦ 금요일 저녁 일곱 시 조금 넘어서. 휴대폰이 울린다. 새 배달이다. 피자와 샐러드, 배달지는 마르찬 십팔 층. 고객 이름은 코발스키. ¦ die Lieferadresse, -n  —  배달 주소 // der Kunde, -n  —  고객 // piepen  —  삑삑 울리다 ¦ Mein Handy piept: eine neue Tour, Pizza und Salat, ...에서 콜론 뒤에 동사 없는 명사 나열이 이어집니다. Name des Kunden: Kowalski에서 des Kunden은 2격입니다. Kunde는 약변화 남성명사입니다. ¦ 흔한 폴란드계 성인 Kowalski는 독일에서도 흔한 성이지만 이 이름이 3화·20화의 사건과 연결되는지는 독자만 의심할 수 있습니다. 시간과 장소를 구체적으로 서술해 긴장감을 쌓습니다. ¦ piept는 현재형(Präsens)으로 서술 속 현재 장면을 묘사하며 이어지는 구절은 동사가 없는 생략문입니다.
Jonas ¦ Kowalski. Es gibt Tausende in Berlin. Trotzdem schlägt mein Herz plötzlich schneller. Ich sage mir, dass das Unsinn ist, und fahre los. ¦ 코발스키. 베를린에는 수천 명이 있다. 그런데도 심장이 갑자기 빨리 뛴다. 말도 안 되는 생각이라고 스스로에게 말하고 출발한다. ¦ der Unsinn (단수)  —  말도 안 되는 일 // losfahren  —  출발하다 // trotzdem  —  그럼에도 ¦ Es gibt Tausende in Berlin에서 Tausende는 수사의 명사화입니다. Ich sage mir, dass das Unsinn ist, und fahre los에서 dass절의 정동사 ist가 끝에 오고 fahre ... los에서 분리동사 losfahren의 los가 끝에 옵니다. ¦ sich etwas sagen은 '스스로에게 ~라고 말하다'를 뜻합니다. 이성과 직감 사이의 갈등을 한 문장으로 표현합니다. ¦ gibt, schlägt, sage, ist, fahre ... los는 모두 현재형(Präsens)으로 서술 속 현재 장면을 묘사합니다.
Jonas ¦ Das Hochhaus ist ein Plattenbau aus den Siebzigern, grau, mit Balkonen voller Satellitenschüsseln. Im Aufzug riecht es nach Reinigungsmittel und nach Essen aus vierzig Küchen. ¦ 고층 건물은 칠십 년대 프리패브 건물이고 회색이며 위성 안테나로 가득한 발코니가 달려 있다. 엘리베이터 안에서는 세제 냄새와 마흔 가구 부엌의 음식 냄새가 난다. ¦ der Plattenbau, -ten  —  프리패브(조립식) 건물 // die Satellitenschüssel, -n  —  위성 안테나 // das Reinigungsmittel, -  —  세제 ¦ Das Hochhaus ist ein Plattenbau aus den Siebzigern에서 aus den Siebzigern은 '칠십 년대의'를 뜻합니다. Im Aufzug riecht es nach Reinigungsmittel und nach Essen aus vierzig Küchen에서 riechen nach + 3격이 쓰입니다. ¦ Plattenbau는 동독 시절 조립식 대형 패널로 지은 주택으로 마르찬에는 이런 건물이 많습니다. 후각으로 장면을 구체화하는 서술은 이 시리즈의 특징입니다. ¦ ist와 riecht는 현재형(Präsens)으로 서술 속 현재 장면을 묘사합니다.
Jonas ¦ Achtzehnter Stock. Die Tür mit der Nummer einhundertfünfundsiebzig. Ich klingle. Drinnen höre ich Schritte, langsam, gleichmäßig, begleitet von einem metallischen Klacken. ¦ 십팔 층. 백칠십오 번 문. 초인종을 누른다. 안쪽에서 발소리가 들린다. 느리고 일정하고, 금속이 부딪히는 소리가 함께 난다. ¦ klingeln  —  초인종을 누르다 // gleichmäßig  —  일정한 // das Klacken (단수)  —  딱딱 하는 소리 ¦ Achtzehnter Stock와 Die Tür mit der Nummer ...는 동사 없는 생략문입니다. Drinnen höre ich Schritte, ..., begleitet von einem metallischen Klacken에서 begleitet von + 3격은 과거분사 구문입니다. ¦ 금속성 소리는 목발이나 보행 보조기의 소리를 암시합니다. 직접 말하지 않고 소리로 사고의 후유증을 보여 주는 서술입니다. ¦ klingle, höre는 현재형(Präsens)으로 서술 속 현재를 말하고 나머지 구절은 동사가 없습니다.
Nina ¦ Moment! Ich komme! Papa, bleib sitzen, ich mache das! Entschuldigung, die Klingel ist so laut, er erschrickt immer. ¦ 잠깐만요! 가요! 아빠, 앉아 있어요, 제가 열게요! 죄송해요, 초인종이 너무 시끄러워서 아빠가 늘 놀라세요. ¦ erschrecken (erschrickt – erschrak – erschrocken)  —  놀라다 // sitzen bleiben  —  앉아 있다 // laut  —  시끄러운 ¦ bleib sitzen은 du 명령형이고 ich mache das!는 일을 맡겠다는 구어체입니다. die Klingel ist so laut, er erschrickt immer에서 so는 정도를 강조하고 erschrickt는 현재형입니다. ¦ 사과하는 딸의 말에서 아버지가 후유증으로 놀라기 쉽다는 사실이 드러납니다. 설명 없이 일상의 말로 사고의 흔적을 보여 줍니다. ¦ komme, mache, ist, erschrickt는 현재형(Präsens)이고 bleib는 명령형입니다.
Jonas ¦ Eine junge Frau, vielleicht Anfang zwanzig, öffnet. Hinter ihr, am Küchentisch, sitzt ein Mann mit grauem Haar, die Krücken an die Stuhllehne gelehnt. ¦ 스물 갓 넘은 듯한 젊은 여성이 문을 연다. 그 뒤 부엌 식탁에는 회색 머리의 남자가 앉아 있고, 목발은 의자 등받이에 기대어 있다. ¦ die Krücke, -n  —  목발 // die Stuhllehne, -n  —  의자 등받이 // anlehnen  —  기대어 놓다 ¦ Eine junge Frau, vielleicht Anfang zwanzig, öffnet에서 vielleicht Anfang zwanzig는 삽입된 나이 추정이고 주어-동사 사이에 놓여 있습니다. die Krücken an die Stuhllehne gelehnt는 과거분사 구문으로 상태를 나타냅니다. ¦ Anfang zwanzig는 '이십 대 초반'이라는 표현입니다. 장면 묘사만으로 코발스키임을 암시하며 독자도 이제 알아챕니다. ¦ öffnet, sitzt는 현재형(Präsens)이고 gelehnt는 과거분사로 목발이 놓인 상태를 나타냅니다.
Jonas ¦ Guten Abend. Ihre Bestellung von Pizzeria Napoli. Zweimal Margherita, einmal Salat. Das macht neunzehn Euro fünfzig. ¦ 안녕하세요. 피자 나폴리에서 주문하신 음식입니다. 마르게리타 두 판과 샐러드 하나요. 십구 유로 오십 센트입니다. ¦ die Bestellung, -en  —  주문 // zweimal  —  두 번, 두 개 // das macht  —  합계는 ~입니다 ¦ Ihre Bestellung von Pizzeria Napoli는 동사 없는 인사말입니다. Das macht neunzehn Euro fünfzig에서 macht는 합계를 말하는 정형 표현입니다. ¦ Das macht ...는 계산할 때 쓰는 관용 표현입니다. 틀에 박힌 배달 문구가 오히려 긴장을 낮추는 일상의 순간을 만듭니다. ¦ macht는 현재형(Präsens)으로 현재의 합계를 말하며 나머지는 동사가 없는 생략문입니다.
Nina ¦ Danke. Papa, hast du das Geld? Ach, ich habe es. Behalten Sie den Rest. Sie sehen müde aus, kommen Sie rein, einen Tee? ¦ 고맙습니다. 아빠, 돈 있어요? 아, 제가 가지고 있어요. 거스름돈은 가지세요. 피곤해 보이세요, 들어와서 차 한 잔 하실래요? ¦ behalten  —  간직하다, 가지다 // der Rest, -e  —  나머지, 거스름돈 // reinkommen  —  들어오다 ¦ Behalten Sie den Rest는 Sie 명령형으로 거스름돈을 팁으로 주겠다는 말입니다. kommen Sie rein은 분리동사 hereinkommen의 구어체입니다. 마지막 einen Tee?는 동사 없는 권유문입니다. ¦ Behalten Sie den Rest는 팁을 줄 때 쓰는 정형 표현입니다. 배달원에게도 따뜻하게 말을 거는 딸의 태도에서 이 가족의 성품이 드러납니다. ¦ hast, habe는 현재형이고 Behalten, kommen은 명령형으로 지금의 요청과 권유를 말합니다.
Jonas ¦ Ich dürfte eigentlich nicht. Aber ich ... sage ja. Zehn Minuten, die Lieferzeit erlaubt es noch. ¦ 원래는 안 되는데요. 하지만... 네, 그러겠습니다. 십 분 정도는 배달 시간상 괜찮아요. ¦ dürfen  —  ~해도 되다 // eigentlich  —  원래는 // die Lieferzeit  —  배달 시간 ¦ Ich dürfte eigentlich nicht은 접속법 II(dürfte)로 정중하게 거절하는 표현이며 nicht 뒤에 동사가 생략되었습니다. Aber ich ... sage ja에서 말줄임표가 망설임을 나타냅니다. ¦ eigentlich는 '원래는, 사실은'이라는 뜻의 완충어입니다. 알면서도 안으로 들어가는 선택은 호기심과 연민에서 나온 행동입니다. ¦ dürfte는 접속법 II(Konjunktiv II)이고 sage, erlaubt는 현재형(Präsens)입니다.
Kowalski ¦ Setzen Sie sich, junger Mann. Ich stehe nicht gern auf, wenn ich nicht muss. Das ist meine Tochter Nina, und ich bin Piotr. ¦ 앉으세요, 젊은이. 꼭 필요하지 않을 땐 일어나기 싫어서요. 이쪽은 제 딸 니나이고 저는 피오트르입니다. ¦ aufstehen  —  일어서다 // gern  —  기꺼이 // die Tochter, Töchter  —  딸 ¦ Setzen Sie sich는 재귀동사 sich setzen의 Sie 명령형입니다. Ich stehe nicht gern auf, wenn ich nicht muss에서 wenn절의 muss 뒤에 aufstehen이 생략되었습니다. ¦ Das ist meine Tochter ..., und ich bin ...은 자기소개의 정형 문장입니다. 서로 이름을 말하는 것은 배달원과 고객의 관계를 넘어서는 첫걸음입니다. ¦ 명령형 Setzen과 현재형 stehe ... auf, ist, bin은 현재의 상황을 말합니다.
Jonas ¦ Jonas. Freut mich. Sie haben eine schöne Aussicht. Man sieht fast bis zum Fernsehturm. ¦ 요나스입니다. 반갑습니다. 전망이 좋으시네요. 텔레비전 탑까지 거의 보여요. ¦ die Aussicht, -en  —  전망 // der Fernsehturm  —  텔레비전 탑 // fast  —  거의 ¦ Freut mich는 Das freut mich의 생략형입니다. Man sieht fast bis zum Fernsehturm에서 man은 일반적 주어이고 bis zum은 bis zu dem의 축약입니다. ¦ schöne Aussicht는 자주 하는 칭찬의 말입니다. 어색한 침묵을 풀기 위한 가벼운 화제 선택입니다. ¦ Freut, sieht는 현재형(Präsens)이고 haben은 현재의 상태를 말합니다.
Kowalski ¦ Die Aussicht war der Grund, warum wir hierhergezogen sind. Früher, als ich noch auf dem Bau gearbeitet habe, habe ich jeden Tag von oben auf Berlin geblickt. Jetzt blicke ich nur noch von unten auf mein Leben. ¦ 이 전망이 우리가 이사 온 이유였어요. 예전에 건설 현장에서 일할 때는 매일 위에서 베를린을 내려다봤죠. 지금은 아래에서 제 삶을 올려다볼 뿐입니다. ¦ hierherziehen  —  이쪽으로 이사 오다 // der Bau  —  건설 현장 // blicken  —  바라보다 ¦ Die Aussicht war der Grund, warum wir hierhergezogen sind에서 warum절은 현재완료로 sind이 끝에 옵니다. als ich noch auf dem Bau gearbeitet habe는 과거의 반복되는 시점을 나타내는 als절입니다. ¦ von oben auf Berlin blicken과 von unten auf mein Leben blicken의 대비가 사고 후 삶의 변화를 비유합니다. 이 한 문장 안에 직업과 신체의 변화가 압축되어 있습니다. ¦ war는 과거형이고 hierhergezogen sind, gearbeitet habe, habe ... geblickt는 현재완료이며 blicke는 현재형(Präsens)입니다.
Nina ¦ Papa, bitte. Wir haben Gäste. Er hatte vor vier Jahren einen Unfall, Herr ... Jonas. Er fiel von einem Gerüst. Seitdem ist alles anders. ¦ 아빠, 제발요. 손님이 계시잖아요. 아빠가 사 년 전에 사고를 당하셨어요, 요나스 씨. 비계에서 떨어지셨죠. 그때부터 모든 게 달라졌어요. ¦ der Gast, Gäste  —  손님 // fallen (fiel – gefallen)  —  떨어지다 // seitdem  —  그 이후로 ¦ Er hatte vor vier Jahren einen Unfall에서 hatte는 haben의 과거형입니다. Er fiel von einem Gerüst에서 fiel은 fallen의 과거형이고 von + 3격이 쓰입니다. Seitdem ist alles anders는 sein + 형용사 구문입니다. ¦ einen Unfall haben은 '사고를 당하다'를 뜻하는 연어입니다. 요나스가 이미 알고 있는 사실을 딸의 입으로 듣게 되는 극적 아이러니의 순간입니다. ¦ hatte와 fiel은 과거형(Präteritum)으로 과거의 사고를 서술하고 ist는 현재형으로 현재의 상태를 말합니다.
Jonas ¦ Mir stockt der Atem. Ich halte meine Teetasse so fest, dass die Knöchel weiß werden. Ich weiß, dass ich jetzt etwas sagen müsste. Ich weiß aber auch, dass ich es nicht darf. ¦ 숨이 막힌다. 찻잔을 너무 세게 쥐어 손마디가 하얘진다. 지금 뭔가 말해야 한다는 걸 안다. 하지만 말해서는 안 된다는 것도 안다. ¦ der Atem (단수)  —  숨 // der Knöchel, -  —  손마디 // jemandem stockt der Atem  —  숨이 멎다 ¦ Mir stockt der Atem에서 stocken은 3격(mir)을 취하는 표현입니다. Ich halte meine Teetasse so fest, dass die Knöchel weiß werden에서 so ..., dass ...는 결과를 나타냅니다. Ich weiß aber auch, dass ich es nicht darf에서 darf 뒤의 동사가 생략되었습니다. ¦ ich müsste와 ich darf nicht의 대조는 요나스의 윤리적 딜레마를 보여 줍니다. 이해 충돌과 비밀유지 의무가 입을 막는 상황입니다. ¦ stockt, halte, weiß, darf는 현재형(Präsens)이고 werden은 현재형, müsste는 접속법 II로 당위를 말합니다.
Jonas ¦ Das tut mir leid. Das war bestimmt eine schwere Zeit. Sind Sie ... gut versorgt? Rechtlich, meine ich. Hatten Sie Unterstützung? ¦ 안타깝습니다. 분명 힘든 시간이었겠군요. 충분히... 지원은 받고 계신가요? 법적으로 말이에요. 도움을 받으셨습니까? ¦ bestimmt  —  분명히 // versorgt  —  보살핌을 받는 // die Unterstützung (단수)  —  지원 ¦ Das tut mir leid는 유감을 나타내는 정형 표현입니다. Sind Sie ... gut versorgt?는 sein + 과거분사의 상태수동 의문입니다. Hatten Sie Unterstützung?은 과거형 결정의문문입니다. ¦ 직접적인 법적 조언은 피하고 질문을 통해 가능성을 열어 두는 방식입니다. Rechtlich, meine ich는 말하려는 방향을 한정하는 정정 표현입니다. ¦ tut, Sind는 현재형이고 war는 과거형, Hatten은 과거형(Präteritum)으로 지난 시간과 지원 여부를 묻습니다.
Kowalski ¦ Unterstützung? Die Berufsgenossenschaft hat gesagt, es sei meine eigene Schuld gewesen. Ich hätte die Sicherung nicht beachtet. Das stand so im Bericht. ¦ 지원이요? 산업재해보험조합은 제 잘못이었다고 했어요. 제가 안전 장치를 지키지 않았다고요. 보고서에 그렇게 쓰여 있었죠. ¦ die Berufsgenossenschaft  —  산업재해보험조합 // beachten  —  주의를 기울이다, 지키다 // der Bericht, -e  —  보고서 ¦ es sei meine eigene Schuld gewesen과 Ich hätte die Sicherung nicht beachtet는 접속법 I·II로 남의 주장을 간접적으로 전달합니다. Das stand so im Bericht에서 stand는 stehen의 과거형입니다. ¦ 보고서에 적힌 대로 일을 처리하는 보험 기관은 공식 문서에 크게 의존합니다. 허위 보고서가 피해자의 보상을 막는 구조를 보여 줍니다. ¦ hat gesagt는 현재완료이고 sei ... gewesen, hätte ... beachtet는 간접화법의 접속법이며 stand는 과거형(Präteritum)입니다.
Nina ¦ Aber das stimmt nicht! Papa hat immer gesagt, es gab kein Geländer. Zwei Jahre kämpfen wir schon, und kein Anwalt will den Fall nehmen.
