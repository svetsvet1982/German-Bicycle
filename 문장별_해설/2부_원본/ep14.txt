# 2부 14화: Samstags in der Mieterberatung / 토요일의 임차인 상담소
Jonas ¦ Samstagmorgen, kurz vor zehn. Vor der Beratungsstelle in der Hasenheide stehen schon fünf Leute. ¦ 토요일 아침, 열 시 직전. 하젠하이데의 상담소 앞에는 벌써 다섯 명이 서 있다. ¦ kurz vor + 3격  —  ~직전에 // die Beratungsstelle, -n  —  상담소 // stehen (stand – gestanden)  —  서 있다 ¦ Samstagmorgen은 시간 표현 명사로 문두에 놓인 독립 구절이고, 이어지는 문장은 Vor der Beratungsstelle가 문두에 와서 정동사 stehen이 2번째, 주어 fünf Leute가 뒤에 옵니다. ¦ kurz vor zehn은 '열 시 직전에'라는 뜻으로 시각을 가리킵니다. Samstagmorgen처럼 요일과 시간대를 붙여 쓰면 '토요일 아침'이라는 시간 부사가 됩니다. ¦ stehen은 현재형(Präsens)으로 서술 속 현재 장면을 묘사합니다.
Elif ¦ Da bist du ja, pünktlich auf die Minute. Komm, ich zeige dir deinen Platz. ¦ 왔네, 정확히 시간 맞춰서. 와, 네 자리 보여 줄게. ¦ pünktlich  —  시간을 지키는 // auf die Minute  —  정각에 // der Platz, Plätze  —  자리 ¦ Da bist du ja에서 ja는 상대의 도착을 반가워하는 불변화사입니다. Komm은 du 명령형이고 ich zeige dir deinen Platz에서 dir는 3격, deinen Platz는 4격입니다. ¦ 이제 둘은 du를 쓰는 사이가 되었습니다(13화 마지막의 호칭 변화). auf die Minute는 '1분도 틀리지 않고'라는 뜻입니다. ¦ bist와 zeige는 현재형(Präsens)으로 지금의 상황과 곧 하려는 행동을 말합니다.
Jonas ¦ Mein Platz? Ich dachte, ich sitze einfach neben dir. ¦ 내 자리요? 그냥 네 옆에 앉는 줄 알았는데. ¦ dachte  —  생각했다 (denken의 과거형) // einfach  —  그냥 // neben + 3격  —  ~의 옆에 ¦ Ich dachte, ich sitze ...에서 dachte는 과거형이고 뒤의 ich sitze는 dass 없이 이어진 내용으로 주절 어순입니다. neben dir는 위치를 나타내는 neben + 3격입니다. ¦ Ich dachte, ...는 '~인 줄 알았다'는 뜻으로 예상이 틀렸을 때 쓰는 표현입니다. 법률사무소의 개인 방과 비교해 소박한 상담소의 분위기를 예고합니다. ¦ dachte는 과거형(Präteritum)으로 예상했던 과거의 생각을, sitze는 현재형으로 그 생각의 내용을 말합니다.
Elif ¦ Das hier ist dein Platz. Ein Klapptisch, zwei Stühle, eine Thermoskanne Tee. Luxus pur. ¦ 여기가 네 자리야. 접이식 탁자 하나, 의자 둘, 보온병에 담긴 차. 최고의 호사지. ¦ der Klapptisch, -e  —  접이식 탁자 // die Thermoskanne, -n  —  보온병 // Luxus pur  —  순수한 호사 (반어) ¦ Das hier ist dein Platz는 지시대명사 Das hier로 장소를 가리키는 평서문입니다. 뒤 문장은 동사 없이 물건을 나열하는 생략문입니다. ¦ Luxus pur는 반어적인 표현으로 '이게 바로 사치다'라는 뜻입니다. 변호사 시절의 안락한 사무실과 대비되는 소박함을 유머로 말합니다. ¦ ist는 현재형(Präsens)이고 나열 문장은 동사가 없어 시제 표지가 없습니다.
Jonas ¦ Ich hatte früher ein Eckbüro mit Blick auf den Landwehrkanal. Aber ehrlich: Das hier gefällt mir besser. ¦ 예전엔 란트베어 운하가 보이는 모퉁이 사무실이 있었어요. 그런데 솔직히 여기가 더 마음에 들어. ¦ das Eckbüro, -s  —  모퉁이 사무실 // der Blick (단수)  —  전망 // gefallen (gefiel – gefallen)  —  마음에 들다 ¦ Ich hatte früher ein Eckbüro mit Blick auf den Landwehrkanal에서 mit Blick auf + 4격은 '~이 보이는'이라는 뜻입니다. Das hier gefällt mir besser에서 gefallen은 3격 mir와 함께 쓰며 besser는 gut(gern)의 비교급입니다. ¦ jemandem gefallen은 '~의 마음에 든다'를 뜻하고 주어가 마음에 드는 대상(Das hier)입니다. Aber ehrlich는 솔직한 속마음을 털어놓는 완충 표현입니다. ¦ hatte는 과거형(Präteritum)으로 과거의 상태를, gefällt는 현재형(Präsens)으로 현재의 감정을 나타냅니다.
Elif ¦ Sag das nicht zu laut, sonst bildest du dir noch etwas darauf ein. Also, bereit für den ersten Fall? ¦ 너무 크게 말하지 마, 안 그러면 우쭐해질 거야. 자, 첫 사건 맞을 준비 됐어? ¦ sich etwas einbilden auf + 4격  —  ~을 뽐내다, 우쭐해하다 // sonst  —  그렇지 않으면 // der Fall, Fälle  —  사건, 경우 ¦ Sag das nicht zu laut는 du 명령형의 부정이고 sonst bildest du dir ... ein은 분리동사 einbilden의 ein이 문장 끝에 옵니다. bereit für + 4격은 '~에 준비가 된'이라는 구문입니다. ¦ sich etwas auf etwas einbilden은 '~에 대해 은근히 자만하다'는 뜻입니다. 농담으로 상담소의 소탈한 분위기를 칭찬하는 말입니다. ¦ 명령형과 현재형은 지금의 대화 흐름을 나타내고 bildest ... ein은 현재형(Präsens)입니다.
Jonas ¦ Bereit, würde ich sagen. Zumindest so bereit, wie man nach zwei Jahren Konzernrecht sein kann. ¦ 준비됐다고 해야겠죠. 적어도 이 년간 기업법만 다룬 사람이 될 수 있는 만큼은요. ¦ zumindest  —  적어도 // das Konzernrecht (단수)  —  기업결합법, 그룹법 // würde ... sagen  —  ~라고 하겠다 (완곡) ¦ würde ich sagen은 접속법 II의 würde + 동사원형으로 단정을 피하는 완곡한 표현입니다. so bereit, wie man ... sein kann은 so ... wie 동등 비교이고 kann이 절 끝에 옵니다. ¦ würde ich sagen은 '~라고 할 수 있겠죠'라는 조심스러운 의견을 나타냅니다. Konzernrecht는 대기업 관련 법을 가리켜 소규모 임차인 법과 대비를 이룹니다. ¦ würde ... sagen은 접속법 II(Konjunktiv II)이고, kann은 현재형(Präsens)입니다.
Elif ¦ Dann fang mit dem Gespräch an, nicht mit dem Gesetz. Hör erst mal zu, bevor du Paragrafen zitierst. ¦ 그럼 법이 아니라 대화로 시작해. 법 조항을 인용하기 전에 먼저 잘 들어. ¦ anfangen mit + 3격  —  ~로 시작하다 // zuhören  —  귀 기울이다 // zitieren  —  인용하다 ¦ fang ... an과 hör ... zu는 du 명령형이며 분리동사의 접두사가 문장 끝에 옵니다. bevor du Paragrafen zitierst는 시간 종속절로 정동사 zitierst가 끝에 있습니다. ¦ erst mal은 '일단, 우선'이라는 구어 표현입니다. 법률가가 먼저 사람의 이야기를 들어야 한다는 상담소의 원칙을 말합니다. ¦ 명령형과 현재형 zitierst는 지금 주는 조언을 나타냅니다.
Jonas ¦ Frau Nowak, nehmen Sie bitte Platz. Möchten Sie einen Tee? ¦ 노바크 씨, 앉으세요. 차 드시겠어요? ¦ Platz nehmen  —  자리에 앉다 // der Tee, -s  —  차 ¦ nehmen Sie bitte Platz는 Sie 명령형이며 Platz nehmen은 '앉다'를 뜻하는 관용 표현입니다. Möchten Sie einen Tee?는 정중한 의문문입니다. ¦ Platz nehmen은 Setzen Sie sich보다 약간 공식적이고 정중한 표현입니다. 먼저 차를 권하는 것은 Elif가 가르친 '대화로 시작'을 그대로 따른 것입니다. ¦ 명령형과 möchten은 지금 하는 권유를 나타냅니다.
Frau Nowak ¦ Danke, nein. Ich bin so aufgeregt, dass ich keinen Schluck hinunterbekäme. ¦ 고맙지만 괜찮아요. 너무 긴장해서 한 모금도 못 넘길 것 같아요. ¦ aufgeregt  —  흥분한, 긴장한 // der Schluck, -e  —  한 모금 // hinunterbekommen  —  삼키다, 넘기다 ¦ so ..., dass ...는 결과를 나타내는 구문입니다. keinen Schluck hinunterbekäme는 접속법 II(bekäme)로 '넘길 수 없을 것 같다'는 가상적 결과를 말합니다. 정동사 hinunterbekäme는 dass절 끝에 놓입니다. ¦ keinen Schluck hinunterbekommen은 '한 모금도 못 삼키다'라는 구어적 과장 표현입니다. 극도의 긴장을 드러냅니다. ¦ bin은 현재형(Präsens)이고 hinunterbekäme는 접속법 II(Konjunktiv II)로 비현실적 가정을 나타냅니다.
Jonas ¦ Das verstehe ich. Erzählen Sie mir einfach, was passiert ist. Wir haben Zeit. ¦ 이해해요. 무슨 일이 있었는지 편하게 말해 주세요. 시간은 충분합니다. ¦ passieren  —  일어나다 // verstehen  —  이해하다 // die Zeit  —  시간 ¦ Erzählen Sie mir ...는 Sie 명령형이고 was passiert ist는 간접의문절로 현재완료 passiert ist에서 ist가 맨 끝에 옵니다. Wir haben Zeit는 시간이 있음을 알리는 짧은 평서문입니다. ¦ Wir haben Zeit는 상대를 안심시키는 말입니다. 변호사 시절의 빠듯한 시간 개념과 다른 상담소의 태도를 보여 줍니다. ¦ verstehe, haben은 현재형(Präsens)이고 passiert ist는 현재완료(Perfekt)로 이미 일어난 사건을 말합니다.
Frau Nowak ¦ Mein Vermieter hat mir geschrieben, dass er die Miete um vierzig Prozent erhöht. Nach der Sanierung. ¦ 집주인이 편지를 보냈는데, 수리 후에 월세를 사십 퍼센트 올린대요. ¦ der Vermieter, -  —  집주인, 임대인 // erhöhen  —  올리다 // die Sanierung, -en  —  (건물) 개보수 ¦ Mein Vermieter hat mir geschrieben, dass ...에서 dass절은 정동사 erhöht가 맨 끝에 옵니다. um vierzig Prozent의 um은 차이·증가분을 나타내는 전치사입니다. ¦ Sanierung은 낡은 건물을 고쳐서 가치를 올리는 개보수를 말하며, 이를 이유로 월세를 올리는 경우가 많아 사회 문제가 됩니다. ¦ hat ... geschrieben은 현재완료(Perfekt)이고 erhöht는 현재형으로 계획된 인상을 말합니다.
Jonas ¦ Vierzig Prozent? Das ist erheblich. Seit wann wohnen Sie in der Wohnung? ¦ 사십 퍼센트요? 상당하네요. 이 집에는 언제부터 사셨어요? ¦ erheblich  —  상당한 // seit wann  —  언제부터 // die Wohnung, -en  —  집, 아파트 ¦ Seit wann wohnen Sie ...?는 시간의 시작점을 묻는 의문문입니다. seit는 3격 또는 의문사 wann과 결합해 지속의 시점을 묻습니다. ¦ Seit wann은 '언제부터 지금까지'를 묻는 정형 표현이며 대답은 seit + 3격이나 seit + 시점으로 합니다. 거주 기간은 임대료 인상 판단에 중요한 사실입니다. ¦ wohnen은 현재형(Präsens)으로, 독일어에서는 과거부터 계속되는 일을 seit와 함께 현재형으로 묻습니다.
Frau Nowak ¦ Seit einunddreißig Jahren. Ich habe dort meine Kinder großgezogen. ¦ 삼십일 년째요. 거기서 아이들을 키웠어요. ¦ großziehen (zog groß – großgezogen)  —  키우다, 양육하다 // das Kind, -er  —  아이 // einunddreißig  —  삼십일 ¦ Seit einunddreißig Jahren은 seit + 3격 복수이고 großgezogen은 분리동사 großziehen의 과거분사입니다. habe ... großgezogen는 현재완료이며 meine Kinder가 4격 목적어입니다. ¦ 독일어 숫자 31은 einunddreißig(1과 30)처럼 일의 자리를 먼저 읽습니다. 오래 산 집에 대한 애착과 생활이 걸려 있음을 보여 줍니다. ¦ habe ... großgezogen은 현재완료(Perfekt)로 과거에 있었던 일과 그 결과를 말합니다.
Jonas ¦ Einunddreißig Jahre. Dann haben Sie sicher auch alle Briefe aufgehoben, oder? ¦ 삼십일 년이라, 그럼 편지도 전부 보관해 두셨겠죠? ¦ aufheben (hob auf – aufgehoben)  —  보관하다, 들어 올리다 // sicher  —  분명히 // oder?  —  그렇죠? ¦ Dann haben Sie sicher ... aufgehoben은 현재완료이며 분리동사 aufheben의 과거분사 aufgehoben이 문장 끝에 옵니다. oder?는 확인을 구하는 부가 의문입니다. ¦ Dann을 문두에 두어 앞 정보로부터 논리적 결론을 이끌어 냅니다. 서류 보관은 임대차 분쟁에서 가장 중요한 준비입니다. ¦ haben ... aufgehoben은 현재완료(Perfekt)로 지금까지의 보관 결과를 묻습니다.
Frau Nowak ¦ In einer Schuhschachtel. Ich bin ein bisschen unordentlich, aber ich werfe nichts weg. ¦ 신발 상자에요. 좀 정리를 못 하지만 아무것도 버리지 않아요. ¦ die Schuhschachtel, -n  —  신발 상자 // unordentlich  —  정리되지 않은 // wegwerfen (warf weg – weggeworfen)  —  버리다 ¦ In einer Schuhschachtel은 장소를 나타내는 in + 3격의 생략 답변입니다. ich werfe nichts weg에서 분리동사 wegwerfen의 weg가 문장 끝에 옵니다. ¦ ein bisschen은 '조금'이라는 부사구입니다. 정리는 못 해도 버리지 않는 성격이 오히려 법적 증거가 되는 아이러니입니다. ¦ bin과 werfe ... weg는 현재형(Präsens)으로 일반적인 성향과 습관을 나타냅니다.
Jonas ¦ Dann ist die Schuhschachtel unser wichtigstes Beweismittel. Bringen Sie sie bitte beim nächsten Mal mit. ¦ 그럼 신발 상자가 우리의 가장 중요한 증거가 되겠네요. 다음에 꼭 가져와 주세요. ¦ das Beweismittel, -  —  증거물 // wichtigst-  —  가장 중요한 (최상급) // beim nächsten Mal  —  다음번에 ¦ wichtigstes는 wichtig의 최상급 wichtigst-에 중성 1격 소유관사 뒤 어미 -es가 붙은 형태입니다. Bringen Sie sie ... mit에서 분리동사 mitbringen의 mit가 문장 끝에 옵니다. ¦ beim nächsten Mal은 '다음 기회에'라는 뜻의 정형 표현입니다. 평범한 신발 상자가 증거라는 말로 상대에게 안심과 희망을 줍니다. ¦ ist는 현재형(Präsens)이고 bringen Sie ... mit는 명령형으로 지금 하는 당부를 나타냅니다.
Frau Nowak ¦ Das ist alles? Ich dachte, Sie sagen mir jetzt, dass ich ausziehen muss. ¦ 그게 다예요? 지금 이사 나가야 한다고 말씀하실 줄 알았어요. ¦ ausziehen (zog aus – ist ausgezogen)  —  이사 나가다 // müssen  —  ~해야 하다 // alles  —  모든 것 ¦ Ich dachte, Sie sagen mir jetzt, dass ich ausziehen muss에서 dass절의 정동사 muss가 맨 끝에 옵니다. 앞부분은 dass 없는 주절 어순입니다. ¦ Das ist alles?는 의외로 간단해서 놀랄 때 쓰는 표현입니다. 나쁜 소식을 예상하며 두려워하던 상태에서 벗어나는 순간입니다. ¦ dachte는 과거형(Präteritum)으로 이전의 예상을, sagen과 muss는 현재형으로 예상했던 내용을 말합니다.
Jonas ¦ Im Gegenteil. Vierzig Prozent nach einer Sanierung sind nicht automatisch rechtens. ¦ 반대예요. 개보수 후라고 해서 사십 퍼센트 인상이 자동으로 합법인 건 아닙니다. ¦ im Gegenteil  —  오히려, 반대로 // automatisch  —  자동으로 // rechtens  —  합법적인 ¦ Vierzig Prozent nach einer Sanierung sind nicht automatisch rechtens에서 주어는 복수 취급되는 Vierzig Prozent이며 sind이 사용됩니다. rechtens는 sein과 함께 쓰는 서술 형용사입니다. ¦ Im Gegenteil은 상대의 가정을 정면으로 뒤집는 표현입니다. nicht automatisch는 '자동으로 ~인 것은 아니다'라는 부분 부정입니다. ¦ sind은 현재형(Präsens)으로 일반적인 법적 평가를 나타냅니다.

Aber ich möchte, dass Elif und Milan mitkommen, zumindest bis vor die Tür. ¦ 좋습니다. 하지만 엘리프와 밀란도 최소한 문 앞까지는 같이 가 줬으면 해요. ¦ einverstanden  —  동의하는 // mitkommen  —  함께 가다 // zumindest  —  적어도 ¦ Ich möchte, dass ... mitkommen에서 dass절의 정동사 mitkommen이 끝에 오며 분리동사가 분리되지 않고 한 덩어리로 놓입니다. bis vor die Tür는 '문 앞까지'라는 방향 표현입니다. ¦ Einverstanden은 동의를 표현하는 간결한 말입니다. 혼자 싸우려던 Jonas가 이제는 곁에 있어 줄 사람을 요청하는 변화를 보여 줍니다. ¦ möchte는 현재형이고 mitkommen은 dass절 안에서 현재형(Präsens)으로 쓰였습니다.
Hanna ¦ Das ist die klügste Entscheidung, die Sie bisher getroffen haben. Schönes Wochenende, Herr Keller. ¦ 지금까지 내리신 결정 중에 가장 현명하네요. 좋은 주말 보내세요, 켈러 씨. ¦ klug (klügste)  —  현명한 (최상급) // die Entscheidung, -en  —  결정 // treffen (traf – getroffen)  —  (결정을) 내리다 ¦ die klügste Entscheidung, die Sie bisher getroffen haben에서 klügste는 최상급 어미 -ste에 여성 1격 정관사 뒤 어미 -e가 붙은 것입니다. die는 4격 관계대명사로 관계절 정동사 haben이 끝에 옵니다. ¦ eine Entscheidung treffen은 '결정을 내리다'는 정형 연어입니다. Schönes Wochenende는 주말을 앞두고 쓰는 일반적인 작별 인사입니다. ¦ ist는 현재형(Präsens)이고 getroffen haben은 현재완료(Perfekt)로 지금까지의 경험을 말합니다.
Jonas ¦ Ich lege auf und bleibe noch einen Moment am Straßenrand stehen. Zum ersten Mal seit Monaten habe ich das Gefühl, nicht allein zu kämpfen. ¦ 나는 전화를 끊고 잠시 길가에 서 있는다. 몇 달 만에 처음으로 혼자 싸우는 게 아니라는 느낌이 든다. ¦ auflegen  —  전화를 끊다 // stehen bleiben  —  멈춰 서 있다 // das Gefühl, -e  —  느낌 ¦ Ich lege auf에서 분리동사 auflegen의 auf가 문장 끝에 오고, bleibe ... stehen은 stehen bleiben의 분리된 형태입니다. das Gefühl, nicht allein zu kämpfen은 zu부정사구가 Gefühl을 설명합니다. ¦ das Gefühl haben, ...은 '~라는 느낌이 들다'를 뜻합니다. 이 회차의 핵심 주제인 '혼자가 아님'이 요약되는 문장입니다. ¦ lege ... auf, bleibe ... stehen, habe는 현재형(Präsens)으로 이야기 속 현재 시점을 서술합니다.
