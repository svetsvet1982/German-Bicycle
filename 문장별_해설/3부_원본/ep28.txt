# 3부 28화: Elifs Spätkauf / 엘리프의 스페트카우프
Jonas ¦ Eine halbe Stunde früher stehe ich vor einem Spätkauf an der Müllerstraße und suche nach Blumen. Ich habe noch nie in meinem Leben Blumen für die Mutter einer Freundin gekauft. ¦ 삼십 분 일찍 뮐러 거리의 스페트카우프 앞에 서서 꽃을 찾는다. 친구의 어머니께 드릴 꽃을 산 적은 평생 한 번도 없다. ¦ der Spätkauf, -käufe  —  늦게까지 여는 가게 // suchen nach  —  ~를 찾다 // die Blume, -n  —  꽃 ¦ Eine halbe Stunde früher는 시간 4격 표현입니다. Ich habe noch nie ... Blumen ... gekauft는 현재완료입니다. ¦ für die Mutter einer Freundin은 für + 4격에 2격이 이어집니다. ¦ stehe, suche는 현재형이고 habe ... gekauft는 현재완료입니다.
Verkäufer ¦ Was darf es sein? Rosen sind aus, aber Tulpen habe ich noch. Letzte Lieferung, halb tot, halb schön. ¦ 뭘 드릴까요? 장미는 떨어졌고 튤립은 아직 있어요. 마지막 입고분인데 반쯤 시들고 반쯤 예쁘죠. ¦ die Lieferung, -en  —  입고 // die Rose, -n  —  장미 // aus sein  —  떨어지다 ¦ Was darf es sein?은 판매원의 정형 질문입니다. Rosen sind aus, aber Tulpen habe ich noch에서 대비 구조가 쓰입니다. ¦ halb tot, halb schön은 형용사 병렬입니다. ¦ darf, sind, habe는 현재형입니다.
Jonas ¦ Tulpen sind genau richtig. Ich nehme alle zehn. Und könnten Sie sie in Papier einschlagen, damit es nicht aussieht, als käme ich vom Bahnhofskiosk? ¦ 튤립이 딱 좋아요. 열 송이 다 주세요. 그리고 역 가판대에서 온 것처럼 보이지 않게 종이로 싸 주실 수 있나요? ¦ einschlagen  —  싸다 // genau richtig  —  딱 맞는 // der Bahnhofskiosk, -e  —  역 가판대 ¦ könnten Sie sie ... einschlagen은 접속법 II의 공손한 부탁입니다. damit es nicht aussieht, als käme ich ...에서 damit절과 접속법 II 비교절이 겹칩니다. ¦ Tulpen sind genau richtig는 평가 문장입니다. ¦ nehme는 현재형이고 könnten, käme은 접속법 II입니다.
Verkäufer ¦ Für wen sind die denn? Wenn Sie mich fragen, sehen Sie aus wie ein Mann, der heute Abend nervös ist. ¦ 누구에게 줄 거예요? 제게 물으신다면 오늘 저녁 긴장한 사람처럼 보이세요. ¦ nervös  —  긴장한 // aussehen wie  —  ~처럼 보이다 // fragen  —  묻다 ¦ Wenn Sie mich fragen, sehen Sie aus wie ein Mann, der ... nervös ist에서 wenn절과 관계절이 쓰입니다. Für wen sind die denn?에서 denn은 의문을 부드럽게 합니다. ¦ die는 지시대명사 복수입니다. ¦ sind, fragen, sehen ... aus, ist는 현재형입니다.
Jonas ¦ Ich bin eingeladen. Zum ersten Mal bei der Familie einer Freundin. Nein, einer Kollegin. Nein, ... ach, ich weiß es selbst nicht. ¦ 초대받았어요. 친구 가족 집에는 처음이에요. 아니, 동료요. 아니... 아, 저도 모르겠네요. ¦ einladen  —  초대하다 // die Kollegin, -nen  —  여성 동료 // selbst  —  스스로 ¦ Ich bin eingeladen은 상태 수동입니다. Zum ersten Mal bei der Familie einer Freundin에서 bei + 3격과 2격이 쓰입니다. ¦ Nein, einer Kollegin. Nein, ...는 말을 정정하는 표현입니다. ¦ bin ... eingeladen, weiß는 현재형입니다.
Verkäufer ¦ Dann nehmen Sie auch noch diese Schachtel Baklava. Gratis. Wer so stammelt, braucht Rückendeckung. ¦ 그럼 이 바클라바 상자도 가져가세요. 공짜예요. 이렇게 더듬는 사람에게는 든든한 뒷받침이 필요하니까요. ¦ stammeln  —  더듬거리다 // die Schachtel, -n  —  상자 // gratis  —  공짜로 ¦ Wer so stammelt, braucht Rückendeckung에서 Wer절이 주어입니다. nehmen Sie ... noch는 존칭 명령형입니다. ¦ Rückendeckung는 든든한 지원을 뜻합니다. ¦ nehmen은 명령형이고 stammelt, braucht는 현재형입니다.
Jonas ¦ Ich bedanke mich dreimal und verlasse den Laden mit einer Tüte in der einen und einem Blumenstrauß in der anderen Hand. In meinem Magen flattert ein Schwarm Schmetterlinge. ¦ 세 번 인사하고 한 손에는 봉지, 다른 손에는 꽃다발을 들고 가게를 나선다. 뱃속에서는 나비 떼가 퍼덕인다. ¦ flattern  —  퍼덕이다 // der Schwarm, Schwärme  —  떼 // der Schmetterling, -e  —  나비 ¦ mit einer Tüte in der einen und einem Blumenstrauß in der anderen Hand에서 mit + 3격이 쓰입니다. In meinem Magen flattert ...에서 장소 부사구가 앞에 놓입니다. ¦ sich bedanken은 재귀 동사입니다. ¦ bedanke mich, verlasse, flattert는 현재형입니다.
Jonas ¦ Auf dem Gehweg kommt mir Herr Bauer entgegen, den ich seit Wochen nicht gesehen habe, einen Einkaufswagen voller Zeitungen hinter sich herziehend. ¦ 인도에서 몇 주째 못 본 바우어 씨가 신문이 가득한 장바구니 수레를 끌며 걸어온다. ¦ entgegenkommen  —  마주 오다 // hinter sich herziehen  —  뒤에서 끌다 // die Zeitung, -en  —  신문 ¦ kommt mir Herr Bauer entgegen에서 entgegenkommen은 3격 mir를 취합니다. den ich ... nicht gesehen habe는 관계절입니다. hinter sich herziehend는 현재분사 구문입니다. ¦ seit Wochen은 seit + 3격 복수입니다. ¦ kommt ... entgegen은 현재형이고 gesehen habe는 현재완료입니다.
Herr Bauer ¦ Keller! Was für eine Überraschung. Tulpen im April? Das ist entweder Liebe oder ein schlechtes Gewissen. ¦ 켈러! 이게 웬일이야. 4월에 튤립이라니? 사랑이거나 양심의 가책이겠군. ¦ die Überraschung, -en  —  놀라움 // das Gewissen (단수)  —  양심 // entweder ... oder  —  ~이거나 ~이거나 ¦ Was für eine Überraschung!은 감탄문입니다. Das ist entweder Liebe oder ein schlechtes Gewissen에서 entweder ... oder가 쓰입니다. ¦ ein schlechtes Gewissen haben는 양심이 찔린다는 표현입니다. ¦ ist는 현재형입니다.
Jonas ¦ Weder noch. Ich besuche Elifs Mutter. Und wenn Sie jetzt grinsen, drehe ich um. ¦ 둘 다 아니에요. 엘리프 어머님을 뵈러 가요. 지금 웃으시면 돌아가 버릴 거예요. ¦ besuchen  —  방문하다 // grinsen  —  씩 웃다 // umdrehen  —  돌아서다 ¦ Weder noch는 둘 다 아니라는 생략 표현입니다. wenn Sie jetzt grinsen, drehe ich um에서 umdrehen은 분리동사입니다. ¦ Elifs Mutter에서 Elifs는 고유명사 2격입니다. ¦ besuche, grinsen, drehe ... um은 현재형입니다.
Herr Bauer ¦ Ich grinse nicht, ich strahle. Weißt du, ich habe Hasan Yılmaz gekannt. Er hat mir damals bei einer Räumungsklage geholfen, als niemand sonst sich getraut hat. ¦ 웃는 게 아니라 환하게 웃는 거야. 나는 하산 일마즈를 알았어. 아무도 나서지 않았을 때 퇴거 소송에서 나를 도와줬지. ¦ strahlen  —  환하게 웃다 // sich trauen  —  용기를 내다 // niemand sonst  —  다른 아무도 ¦ Er hat mir damals ... geholfen에서 helfen은 3격 mir를 취합니다. als niemand sonst sich getraut hat은 과거 시점을 나타내는 als절입니다. ¦ Ich habe Hasan Yılmaz gekannt는 현재완료입니다. ¦ strahle, Weißt는 현재형이고 habe ... gekannt, hat ... geholfen, getraut hat은 현재완료입니다.
Jonas ¦ Dann hat die Mieterberatung ihm mehr zu verdanken, als ich wusste. Wussten Sie, dass Elif ihren Vater dabei verloren hat? ¦ 그럼 상담소는 제가 알던 것보다 그분께 더 큰 빚을 졌네요. 엘리프가 그 일 중에 아버지를 잃었다는 걸 아셨나요? ¦ verdanken  —  덕분이다 // verlieren  —  잃다 // dabei  —  그 일에서 ¦ Dann hat die Mieterberatung ihm mehr zu verdanken, als ich wusste에서 haben + zu 부정형과 als절이 쓰입니다. Wussten Sie, dass ...?에서 dass절의 hat이 끝에 옵니다. ¦ jemandem etwas zu verdanken haben는 ~덕분이다라는 표현입니다. ¦ hat ... zu verdanken, wusste, Wussten은 현재형 또는 과거형이며 verloren hat은 현재완료입니다.
Herr Bauer ¦ Natürlich wusste ich es. Ich war bei der Beerdigung. Ich habe damals neben dem Mädchen gestanden und gedacht: Aus der wird entweder eine Kämpferin oder ein gebrochener Mensch. ¦ 물론 알았지. 장례식에도 갔어. 그때 그 소녀 곁에 서서 생각했지. 저 아이는 싸우는 사람이 되거나 부서진 사람이 되겠구나. ¦ die Beerdigung, -en  —  장례식 // der Kämpfer, -  —  싸우는 사람 // gebrochen  —  부서진 ¦ Aus der wird entweder eine Kämpferin oder ein gebrochener Mensch에서 werden aus + 3격과 entweder ... oder가 쓰입니다. Ich habe ... gestanden und gedacht는 현재완료입니다. ¦ Natürlich wusste ich es는 과거형입니다. ¦ wusste, war는 과거형이고 habe ... gestanden, ... gedacht는 현재완료, wird는 현재형입니다.
Jonas ¦ Und? Was ist sie geworden? ¦ 그래서요? 그 아이는 무엇이 되었나요? ¦ werden  —  되다 // und  —  그래서 // was  —  무엇 ¦ Was ist sie geworden?는 werden의 현재완료 의문문이며 sein을 씁니다. Und?는 대답을 재촉합니다. ¦ 짧은 질문입니다. ¦ ist ... geworden은 현재완료입니다.
Herr Bauer ¦ Das, junger Freund, weißt du besser als ich. Und jetzt geh. Frau Yılmaz kocht gewiss, und Verspätung gilt dort als Beleidigung. ¦ 그건 젊은 친구가 나보다 더 잘 알지. 이제 가게. 일마즈 부인이 분명 요리하고 계실 텐데, 거기서는 지각이 모욕이니까. ¦ die Beleidigung, -en  —  모욕 // gewiss  —  분명히 // die Verspätung, -en  —  지각 ¦ Das ... weißt du besser als ich는 비교 구문입니다. Verspätung gilt dort als Beleidigung에서 gelten als + 1격이 쓰입니다. ¦ jetzt geh는 du 명령형입니다. ¦ weißt, kocht, gilt는 현재형이고 geh는 명령형입니다.
Jonas ¦ Sonntagabend. Elif hat mich zu sich nach Hause eingeladen, und ich stehe mit einem Blumenstrauß vor einer Tür in Wedding. ¦ 일요일 저녁. 엘리프가 나를 집에 초대했고, 나는 꽃다발을 들고 베딩의 한 문 앞에 서 있다. ¦ der Blumenstrauß, -sträuße  —  꽃다발 // einladen  —  초대하다 // vor einer Tür  —  문 앞에 ¦ Elif hat mich ... eingeladen은 분리동사 einladen의 현재완료입니다. mit einem Blumenstrauß는 mit + 3격이고 vor einer Tür는 vor + 3격입니다. ¦ nach Hause eingeladen은 집으로 초대했다는 표현입니다. ¦ hat ... eingeladen은 현재완료이고 stehe는 현재형입니다.
Elif ¦ Du hast Blumen mitgebracht? Meine Mutter wird sofort glauben, du hättest ernste Absichten. ¦ 꽃을 가져왔어? 우리 어머니는 네가 진지한 뜻이 있다고 단번에 믿으실 거야. ¦ die Absicht, -en  —  의도 // ernst  —  진지한 // glauben  —  믿다 ¦ Meine Mutter wird sofort glauben, du hättest ernste Absichten에서 wird는 미래형이고 hättest는 접속법 II로 간접화법입니다. ¦ ernste Absichten haben는 진지한 의도가 있다는 표현입니다. ¦ hast ... mitgebracht는 현재완료이고 wird ... glauben은 미래형, hättest는 접속법 II입니다.
Jonas ¦ Dann nehme ich sie wieder zurück. Ich will keine Missverständnisse. ¦ 그럼 도로 가져갈게. 오해를 사고 싶지 않아. ¦ zurücknehmen  —  도로 가져가다 // das Missverständnis, -se  —  오해 // wollen  —  원하다 ¦ Dann nehme ich sie wieder zurück에서 zurücknehmen은 분리동사입니다. Ich will keine Missverständnisse에서 keine는 복수 4격을 부정합니다. ¦ wieder는 다시라는 부사입니다. ¦ nehme ... zurück, will은 현재형입니다.
Elif ¦ Zu spät, sie hat dich schon durch den Spion gesehen. Komm rein, und zieh die Schuhe aus. ¦ 이미 늦었어, 어머니가 문구멍으로 벌써 봤어. 들어와서 신발 벗어. ¦ der Spion, -e  —  문구멍 // ausziehen  —  벗다 // zu spät  —  너무 늦은 ¦ Komm rein과 zieh die Schuhe aus는 du 명령형이며 분리동사가 쓰입니다. sie hat dich ... gesehen은 현재완료입니다. ¦ durch den Spion은 durch + 4격입니다. ¦ hat ... gesehen은 현재완료이고 Komm, zieh ... aus는 명령형입니다.
Frau Yılmaz ¦ Willkommen, willkommen! Du musst Jonas sein. Elif hat mir so viel von dir erzählt, dass ich dich schon kenne. ¦ 어서 와요! 요나스군이죠. 엘리프가 얘기를 너무 많이 해서 벌써 아는 사람 같아요. ¦ erzählen  —  이야기하다 // kennen  —  알다 // so viel  —  그렇게 많이 ¦ Du musst Jonas sein에서 müssen은 강한 추측을 나타냅니다. Elif hat mir so viel ... erzählt, dass ich dich schon kenne에서 so ... dass 결과절이 쓰입니다. ¦ von dir erzählen은 von + 3격입니다. ¦ musst, kenne는 현재형이고 hat ... erzählt는 현재완료입니다.
Jonas ¦ Guten Abend, Frau Yılmaz. Ich hoffe, sie hat nur Gutes erzählt. Die Blumen sind für Sie. ¦ 안녕하세요, 일마즈 부인. 좋은 얘기만 했길 바랍니다. 꽃은 부인께 드리는 거예요. ¦ nur Gutes  —  좋은 것만 // die Blume, -n  —  꽃 // hoffen  —  바라다 ¦ Ich hoffe, sie hat nur Gutes erzählt에서 dass가 생략되었습니다. Gutes는 형용사의 명사화입니다. ¦ für Sie는 für + 4격입니다. ¦ hoffe, sind는 현재형이고 hat ... erzählt는 현재완료입니다.
Frau Yılmaz ¦ Oh, wie schön! Tulpen. Mein Mann hat mir immer Tulpen geschenkt, im Februar, wenn es sie kaum gab. Sie waren sein Zeichen, dass der Winter endet. ¦ 어머, 예뻐라! 튤립이네요. 남편이 늘 2월에 구하기 힘든 튤립을 선물해 줬어요. 겨울이 끝난다는 그이의 신호였죠. ¦ die Tulpe, -n  —  튤립 // schenken  —  선물하다 // enden  —  끝나다 ¦ Mein Mann hat mir immer Tulpen geschenkt에서 mir는 3격입니다. wenn es sie kaum gab에서 gab는 과거형입니다. ¦ das Zeichen, dass ...는 신호를 설명하는 구문입니다. ¦ hat ... geschenkt는 현재완료이고 gab, waren은 과거형, endet는 현재형입니다.
Elif ¦ Mama, nicht weinen. Er ist doch nur zu Besuch gekommen. ¦ 엄마, 울지 마세요. 요나스는 그냥 놀러 온 거예요. ¦ weinen  —  울다 // der Besuch, -e  —  방문 // nur  —  단지 ¦ nicht weinen은 부정형을 이용한 부드러운 명령입니다. Er ist ... zu Besuch gekommen은 kommen의 현재완료입니다. ¦ zu Besuch kommen은 방문하러 온다는 표현입니다. ¦ ist ... gekommen은 현재완료입니다.
Frau Yılmaz ¦ Ich weine nicht, ich bin gerührt. Das ist ein Unterschied, den nur Mütter kennen. Setzt euch, das Essen ist fertig. ¦ 우는 게 아니라 감동한 거야. 어머니들만 아는 차이지. 앉아, 음식 다 됐다. ¦ gerührt  —  감동한 // der Unterschied, -e  —  차이 // fertig  —  준비된 ¦ ein Unterschied, den nur Mütter kennen에서 den은 관계대명사이며 kennen이 끝에 옵니다. Setzt euch는 ihr 명령형입니다. ¦ gerührt sein은 감동받았다는 표현입니다. ¦ weine, bin, ist, kennen은 현재형이고 Setzt는 명령형입니다.
Jonas ¦ Auf dem Tisch stehen Börek, gefüllte Weinblätter, ein Linsensalat und eine Schüssel Joghurt mit Gurke. Es sieht aus wie ein Fest. ¦ 식탁에는 뵈렉, 포도잎 쌈, 렌틸콩 샐러드, 오이를 넣은 요거트 한 그릇이 차려져 있다. 잔치처럼 보인다. ¦ gefüllt  —  속을 채운 // das Weinblatt, -blätter  —  포도잎 // die Linse, -n  —  렌틸콩 ¦ Auf dem Tisch stehen ...에서 장소 부사구가 앞에 와 도치되었습니다. Es sieht aus wie ein Fest는 분리동사 aussehen과 wie 비교입니다. ¦ eine Schüssel Joghurt는 수량 표현이라 무관사입니다. ¦ stehen, sieht ... aus는 현재형입니다.
Frau Yılmaz ¦ Iss, iss! Du bist zu dünn. Wer Fahrrad fährt, braucht Kraft. Elif, gib ihm noch Börek. ¦ 먹어, 먹어! 너무 말랐어. 자전거 타는 사람은 힘이 필요해. 엘리프, 뵈렉 더 줘라. ¦ dünn  —  마른 // die Kraft, Kräfte  —  힘 // geben  —  주다 ¦ Iss는 essen의 du 명령형(불규칙)이고 gib ihm noch Börek은 geben의 명령형입니다. Wer Fahrrad fährt, braucht Kraft에서 Wer절이 주어입니다. ¦ noch는 더라는 뜻의 부사입니다. ¦ bist, fährt, braucht는 현재형이고 Iss, gib는 명령형입니다.
Elif ¦ Mama hat immer Angst, dass jemand hungrig nach Hause geht.
